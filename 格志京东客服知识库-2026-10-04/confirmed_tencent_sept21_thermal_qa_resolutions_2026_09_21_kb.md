# 2026-09-21 腾讯测试表热敏打印机问题确认规则

状态：Approved / Corrected  
适用范围：中国市场热敏打印机客服、当前知识库的源文档、RAG 卡片、查询映射、索引和测试。  
优先级：本文件覆盖同主题的旧答复；未列出的既有内容保持不变。

## 1. 平台、连接和打印组件

- 在电脑上安装或更换打印机驱动后，必须完全退出并重新启动平台打印组件，回到打印页面重新选择当前打印机，再打印测试单。

## 2. Windows 驱动规则

- 当前官方 Windows 打印机驱动适用于所有打印机型号的 32 位和 64 位 Windows；系统位数不是选择型号或拒绝安装的门槛。
- 安装失败时仍需收集 Windows 版本、准确型号、安装包版本和完整报错；按官方安装包、管理员运行、所需 .NET 运行环境及手动安装路径排查。
- 安装期间可以临时退出杀毒软件，安装完成后立即恢复开启；不得指导永久关闭安全防护。
- DaiBaiPrint/TP874S 安装器崩溃先按运行环境和官方安装包处理，不先归因于 USB。USB 识别只在安装器恢复后再检查。
- CRC/解压校验错误不得忽略：重新下载官方安装包、换保存位置或网络复测；反复出现时转人工技术支持。
- 远程支持证书错误不得绕过证书验证；核对官方地址、系统日期时间和网络，仍失败时改用已确认官方入口或转人工。

## 3. 快递面单尺寸和位置

- 快递面单不需要客户测量：一联/国内快递面单按 `76×130mm`，二联/海外快递面单按 `100×150mm`；选择前仍须核对机器最大纸宽，80mm机型不得推荐100×150mm。
- 非快递标签或客户自定义标签仍按实际宽、高设置，使实际纸张、平台模板和驱动纸张规格一致。
- 预览已经居中而实体纸整体偏移时，在驱动或打印组件中按 `1–2mm` 小步调整边距或水平位置，每次只改一项并打印一张复测。
- 导纸器应轻贴纸边，既不能松到纸张走偏，也不能夹紧到纸张弯曲或起皱。

## 4. 连接、脱机、空白和打印质量

- 脱机/灰色队列先查物理连接、Windows 是否检测到设备和实际端口是否匹配；只有设备已检测到后，才检查脱机/暂停、队列和 Print Spooler。
- 空白页先确认热敏面朝打印头、USB/端口和隐藏打印任务，再打印 Windows 测试页；测试页仍空白或固定半边无字时转人工检查打印头/硬件。
- 打印太淡时逐步提高浓度或灰度阈值；打印太黑、灰底或出现白色杂点时降低浓度和灰度阈值。
- 固定位置白线先清洁打印头；清洁后测试页仍在相同位置持续白线或缺笔画时转人工维修。
- 上盖未同时压紧两侧可能造成虚印、缺印或位置不稳；先正确合盖，再判断浓度或硬件。
- 热敏打印头不单独对客销售；疑似打印头损坏时转人工维修，不承诺单卖配件。

## 5. 红灯、走纸、机械和配件

- 红灯闪烁且缺纸：正确装入热敏纸并合盖，等待机器自动识别纸张；不主动建议客户按走纸键。
- 红灯常亮：依次检查装纸、上盖两侧、纸张传感器、卡纸和进纸通道；窄纸还需核对是否在该型号支持范围内。上述正常但连接不稳定时再检查 USB。
- 打印褶皱或走偏时，导纸器只轻贴纸边，不夹弯纸张；清理胶辊、纸屑、胶渍并换平整纸张复测。
- 异响或不进纸可能与胶辊、齿轮打滑或传感器有关；停止反复打印，关机后检查和清洁传感器，仍异常转人工维修，不指导拆机。
- 上盖卡扣/连接件损坏时收集型号、订单和损坏照片，转人工核对配件；不承诺一定有货或免费补发。
- 拔掉电源后指示灯短暂保持点亮通常是电容余电，与 USB 无关；持续较长时间仍有异常供电表现时停止使用并转人工。

## 6. 外观、SKU 和对客边界

- 部分新款外壳可能不印品牌 Logo，但仍应有型号或纸宽标识。先核对订单、商品页、型号/纸宽标签；一致时说明不影响使用，不得把“无 Logo”扩展成“所有新款都没有型号区分”。
- 某些 SKU 可为灰白配色或随机颜色，功能不变；必须核对当前 SKU/订单。客户质疑错发时不得仅以“功能一样”驳回，应核对后再答复。
- 标准包装以现有治理源为准；除必备包装内容外，额外赠品均按具体 SKU/订单选项确认。
