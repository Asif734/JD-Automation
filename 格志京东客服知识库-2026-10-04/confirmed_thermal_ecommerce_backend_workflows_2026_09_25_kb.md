# 热敏打印机国内电商后台打单确认更新（2026-09-25）


## 1. 范围与证据边界

- 本文件只记录用户逐项确认后的清洗知识，不把原始视频或截图直接导入数据库。
- 适用于 Windows 电脑通过 USB 连接热敏打印机，从国内电商平台后台打印标准快递面单。
- 原始材料中的店铺名称、地址、收件人、订单号、运单号、月结编码、网点、商品及账号信息均不得进入客服回复或检索卡片。
- 视频中的 `TP874H` 只是示例打印机，不是平台强制型号；平台内应选择当前电脑已正确安装且在线的实体打印机。
- 平台页面会改版。下列 2023–2024 年界面路径用于当前确认过的操作参考；入口名称不同或找不到时，先按功能名称查找，仍无法定位则转平台帮助中心或人工客服。
- 本批次只使用清晰可见的界面、按钮和操作顺序；低置信度音频识别内容不进入知识库。


## 2. 国内电商标准快递面单尺寸

- 国内电商平台的标准快递一联面单统一按 `76×130mm` 处理。
- `76×130mm` 规则只适用于标准国内快递面单，不适用于商品标签、自定义单据或海外面单。
- 二联/海外快递面单仍按 `100×150mm` 处理。
- 固定尺寸不代表所有机器都能打印：选择前必须核对机器最大纸宽；80mm 机型不能打印 `100×150mm`。


## 4. 京东/京麦 POP 店铺电脑端打印

主路径：

1. 进入京麦商家后台的 `订单`。
2. 打开 `打单工具`，勾选需要处理的订单。
3. 点击 `打印快递单`。
4. USB 热敏打印机的打单类型选择 `本地打印`，再选择当前实体打印机。
5. 选择物流公司，并按该物流公司的要求填写或选择月结编码、服务产品、网点等信息。
6. 选择对应面单模板，核对订单和包裹数量。
7. 按实际需求选择 `确定打印` 或 `打印并出库`。
8. 已出库订单需要再次打印时，使用页面提供的 `补打快递单` 等入口。

旧版/备用路径：

- `京麦后台 → 订单管理 → 选择订单 → 打印快递单`。
- 该简化路径只作为旧版或不同界面的备用入口；以上主路径为完整流程。

边界：

- `本地打印` 是本批次 USB 热敏打印机证据支持的选择；不得据此承诺 `网页打印` 一定兼容。
- 月结编码、网点和服务产品均为店铺/物流公司专属配置，不得提供通用示例值。


## 8. 客服统一回复边界

- 客户只问“怎么打单”时，先确认具体平台和电脑/手机端；本文件的详细路径只用于 Windows 电脑后台打印。
- 客户明确平台后，只回复该平台对应步骤，不一次列出所有平台。
- 平台找不到打印机时，先确认 Windows 测试页；测试页正常则重启平台打印组件、重新选择当前实体打印机、物流公司和模板。
- 平台界面与本文件不一致、需要店铺专属编码/网点，或执行后仍不能打印时，转平台帮助中心或人工技术支持。
