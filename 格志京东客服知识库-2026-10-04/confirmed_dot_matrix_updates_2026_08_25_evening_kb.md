# 针式打印机已确认更正（2026-08-25 晚间）

来源：`Corrected~Test QnA Verification-2026-08-24-Evening-Dot-Matrix.xlsx` 中已经确认的复核备注。

## 1. 驱动安装入口

- 支持手机/WiFi 的针式打印机要配置 WiFi：选择 `Automatic → 下一步`。
- 要安装 USB 驱动：选择 `USB → 搜索 → 选中设备 → 下一步`。
- 仅支持 USB 的机型选择 Auto 或 USB 都会安装 USB 驱动；对客优先说选 USB。

## 2. 固定白线

- 一般缺笔画先检查色带透明保护膜和安装状态。
- 明显、稳定且每次同位置的固定白线：取下色带，不装色带，用多联纸打印并查看第二联；第二联仍在同一位置缺线即可确认打印头问题。该测试用于排除色带原因。

## 3. 缺纸红灯、后进纸失败和打印头卡住

- 视频出现缺纸红灯亮、后进纸按键不送纸、打印头只轻微移动后回位时：重启，取下色带，观察开机时打印头能否自动移动，检查打印头周围异物；清理后进纸感应器，再测试前进纸；仍无效转人工维修。

## 4. 打印头发热

- 连续打印时打印头发热通常正常，不要触摸。
- 反复停止、烧焦味、冒烟或异常声音时立即暂停使用并转人工售后。

## 5. 卡纸和纸厚扳手

- 卡纸排查时把纸厚扳手调到最高的第 6 档，可改善进纸并减少卡纸。
- 调法：右手拇指把扳手向右按住，再向上推。

## 6. 打印头动一下停一下再继续

- 优先清理隐藏打印任务，不归入打印速度慢。
- Windows 路径：右击开始键 → 运行 → 输入 `SPOOL` → 打开 `printers` → 删除隐藏任务；同时清空全部待打印任务，再重新打印。

## 7. 不开机和电源按钮

- 针式打印机没有 I/O 按钮或独立主开关，只有顶部电源按钮。
- 客户反馈机器不开机时，先更换一个确认有电的插座，再长按电源按钮尝试开机；仍不开机则转人工客服申请维修。
- 不再提供关机静置、断开线缆或其他扩展排障步骤。
- 只有客户明确询问电源按钮位置时，才单独说明顶部电源按钮。

## 8. App 本地模板

- 编辑完成后可把模板保存在速印通本地并重复使用。
- 本地模板不随账号同步，不能转移或导入新手机；换手机后需要重新创建。
- 客服后台制作的模板可搜索。

## 9. Excel 和 Word

- 速印通支持选择 Excel 和 Word 文档。
- 先把文件正确保存到手机本地，再从 App 中打开相同路径选择文件；无需强制转换为 PDF。

## 10. 中文和印度尼西亚语

- 中文和印度尼西亚语可以正常一起打印。
- 客户只问能否打印时简洁回答；实际乱码或缺字时再排查字体和编码。

## 11. 纸张正确但点击打印无反应

- 视频已确认纸张位置正确且缺纸红灯未亮时，不重复要求重新放纸。
- 先打印 Windows 测试页；不打印则换电脑 USB 接口；仍不打印则核对设备端口和驱动端口是否一致。

## 已有内容保持不变

- 前后进纸问题先确认实际进纸方向，再清理对应传感器。
- 打印头卡住时观察开机后是否自动左右移动。
- 可向中国市场客户发送速印通官方下载链接。
- 不建议用针式打印机打印照片。

## 12. 检索消歧补充（2026-08-26）

- 客户只说“打印有白线”且无法从型号、图片或上下文判断产品线时，只询问一次机器型号或机器类型；不得直接套用热敏机清洁打印头话术。
- 针式打印机出现明显、稳定、同位置白线或固定位置笔画缺失时，走“不装色带 + 多联纸查看第二联”的确认流程；非固定或现象不明确时先检查色带透明保护膜和安装状态。
- 驱动已经检测到 `TD630 SZ USB` 等设备时，仍按客户目的分流：配置 WiFi 选 `Automatic`，安装 USB 驱动选 `USB`。
- “打四五张后打印头发烫并停止打印”归入打印头发热分流，不归入普通打印队列故障。
- 针式打印机只描述“打印头不动”时，也要指导观察开机后打印头能否自动左右移动一次。
- 蓝牙搜索不到且面板灯全部熄灭时，先按不开机处理，使用顶部电源按钮；不得指导打开不存在的 I/O 按钮或主开关。
