## 2. 总原则

- 热敏机问题先判断“纸张/模板/驱动/端口/组件/打印头”，不要直接认定机器坏。
- 客户说打印不全、白纸、黑条、偏移、半停时，先要测试页/自检页和打印预览，再看驱动纸张规格。
- 热敏机没有墨水和色带，打印不清楚通常看热敏纸、打印头、浓度/速度/阈值、打印质量。
- 纸张规格必须三处一致：实际纸张、打印预览/模板、驱动纸张规格。
- 手机打印必须确认平台和机型：部分平台支持手机打印，很多平台只能电脑端或需电脑先设置。
- Mac、云打印、自动打单、连续纸、超宽面单等都有边界，不能随口承诺支持。
- 涉及退款、退货、换货、补发、赔偿、维修收费、打印头过保、投诉、物流异常，自动客服只做安抚和信息收集，必须转人工。

## 4. 高频问题与处理规则

### 4.1 纸张、模板、宽度不匹配

典型信号：

- 提示“预览不在打印范围”。
- 打印不全、左右两边缺、右边缺失、文档缩小、格式完全不对。
- 客户使用 100mm 宽面单，但机器最大打印宽度只有 80mm。
- 小标签 40x20 正常，60x20 异常，或型号最大宽度只有 48mm。

处理顺序：

1. 先问实际纸张尺寸和打印内容。
2. 看打印预览尺寸是否与实际纸张一致。
3. 看驱动纸张规格是否与实际纸张一致。
4. 取消驱动里的删除左边/底部空白、固定页面高度、自动旋转等影响项。
5. 若模板内容偏左/偏右，优先在模板里移动模块，再微调驱动起始位置。
6. 若机器最大宽度不支持该纸张，明确说明不支持，并推荐合适机型或纸张。

模板：

> 亲，这个更像纸张规格或模板尺寸不一致。请您先发实际纸张宽高、打印预览截图和驱动纸张规格截图。我们要确认实际纸张、预览模板、驱动规格三处一致；如果纸张宽度超过机器最大打印范围，就需要换纸张或换对应宽度的机器。

### 4.2 打印白纸、不打印、半停

典型信号：

- 打印出白纸、时不时白纸、打一张出一张白纸。
- 打印半张、半停、乱码、机器不出纸。
- 放纸能吸入，但电脑打印异常。

处理顺序：

1. 先看机器是否吸纸，自检页/测试页是否正常。
3. 白纸优先检查驱动名称是否正确、端口是否正确、纸张规格是否错误。
4. 删除 Windows 自带异常纸张规格，如 S1-S3，再重新创建纸张。
5. 换 USB 接口、数据线、电脑测试，排除端口/接口问题。
6. 不规则半停多看端口；每张同一位置半停多看固定页面高度。
7. 仍不行或接口疑似硬件故障，转人工/寄回检测。

模板：

> 亲，白纸/半停我们先分两步判断：机器自检页或电脑测试页是否正常？如果测试页正常，多半是平台组件、模板或纸张规格问题；如果测试页也异常，再看驱动、端口、数据线和机器接口。麻烦先发测试页结果和驱动名称，我继续帮您排查。

### 4.3 打印不清、太浓、黑条、白线

典型信号：

- 打印太浓、一团黑、黑线、黑条。
- 打印不清楚、条码锯齿、局部不清、白条/竖线缺失。
- 重新放纸能正常一张，随后又异常。

处理顺序：

1. 确认是否热敏纸：热敏纸靠近热源会大面积变黑。
2. 先打印自检页或测试页，判断硬件和驱动边界。
3. 清理打印头和滚轴，检查是否粘胶、灰尘、盖子未盖紧、卡扣断裂。
4. 太浓、灰底或白色杂点：降低浓度和灰度阈值。
5. 太淡或不清楚：逐步提高浓度或灰度阈值；条码锯齿还需使用高质量原文件并清理打印头。
6. 固定白线先清洁打印头；自检页在打印宽度范围内仍固定缺失、白线或黑条持续时，可能打印头损坏，转人工维修。打印头不单独对客销售。

模板：

> 亲，打印效果问题先别急着判断机器坏。请先打印一张自检页或测试页，再发当前样张。太黑一般先把驱动里的打印质量/浓度/速度/阈值调低；不清楚或有白线先清理打印头和滚轴。若自检页同样固定缺线或黑条，就需要转人工售后判断打印头。

### 4.4 偏移、首张位置不对、不居中

典型信号：

- 第一张位置不对，后面几张正常。
- 左右偏移、整体偏左/偏右、整体偏下。
- 小标签一张一张打时位置不稳定。

处理顺序：

1. 热敏标签首张可能是学习纸张位置，优先看第二张以后效果。
2. 确认纸张居中、导纸器轻贴纸边但不夹弯纸张。
3. 快递面单固定规格为一联/国内 `76×130mm`、二联/海外 `100×150mm`，但选择前必须核对机器最大纸宽；80mm机型不得推荐100×150mm。非快递标签才按实际宽高设置。
4. 取消删除左边空白/删除底部空白/偏移设置。
5. 预览里能调边距先调预览；预览居中但实物整体偏移时，再按 `1–2mm` 小步调整驱动边距或水平位置。
6. 一张一张打印偏移时，建议连打并按第二张以后效果调试。

模板：

> 亲，热敏标签第一张有时会学习纸张位置，建议先连续打印几张，看第二张以后是否稳定。请确认纸张居中、卡扣夹紧，再检查驱动纸张规格和删除空白/起始位置设置；如果预览里能调边距，优先在模板或预览里调整。

### 4.5 驱动、组件、安装异常

典型信号：

- 驱动装不上、安装被拦截、需要管理员权限。
- 打印组件异常、字体异常、网点异常。
- 测试页正常，但平台/打单软件打印不了。
- 驱动名称和机器型号不一致。

处理顺序：

- 优先确认官方驱动来源及签名并检查应用级权限，不永久关闭杀毒软件或防火墙。
- 仅在官方说明或权限报错需要时以管理员身份运行。
3. 核对机器型号所属的已确认兼容驱动族；驱动名称不必与销售型号逐字相同。TP731S 可用 TP731HS 或 TP874H；TP874H 族已确认覆盖 TP733、TP732、TP731、JPW830、JPW850，TP730G 族已确认覆盖 TP518、JPW760。未列出的型号不得由“等”自行扩展。
4. 安装或更换驱动后，完全退出并重新启动平台打印组件，在打印页面重新选择当前打印机；测试页正常但平台仍不行，再卸载组件重装。
5. 字体异常可尝试组件里的“忽略字体无法显示文本”。
- JD手机App直打与PID安装路径未确认，不提供该设置操作。
7. 仍无法识别或接口异常，换接口/数据线/电脑后转人工。

模板：

> 亲，先看测试页能不能正常打印。如果测试页正常，机器和驱动大概率没问题，下一步看平台打印组件；请重启组件或卸载后重装。如果测试页不正常，我们先核对驱动名称、端口和连接方式，必要时删除旧驱动重新安装。

### 4.6 平台、手机打印、云打印边界

典型信号：

- 客户要自动打单、云打印、外卖单连续纸、苹果/Mac 打印。
- 客户使用老款蓝牙机或不支持 App 的机型。

处理规则：

- 电脑端一般不限制平台，只要平台能选择本机驱动打印。
- 全部格志热敏打印机都支持Android和iOS/iPhone。支持USB的产品可直接USB连接手机，不需要App；使用蓝牙或Wi-Fi连接时使用Grozziie App/速印通。具体型号只用于选择正确的连接步骤；机身未印蓝牙字样不能作为否定手机支持的依据。
- 客户咨询风火递时，先建议从对应电商平台电脑后台直接打印面单/订单，更简单方便；仍坚持使用风火递时，说明当前仅限新用户赠送3个月，并 `reply_then_transfer` 转人工核对资格和办理。
- 自动打单属于打单软件能力，机器本身不能自动识别订单打印。
- 外卖单常见连续纸一般不支持；缝隙热敏纸且高度一致时才可判断。

### 4.7 Windows 10/11 驱动、端口与队列

处理顺序：

1. 先确认 Windows 版本、打印机准确型号，以及驱动包来自已验证的官方/售后来源；当前官方 Windows 打印机驱动适用于所有打印机型号的 32 位和 64 位 Windows，不把系统位数作为安装门槛。
2. 安装驱动时可临时退出或关闭杀毒软件，安装完成后立即恢复开启；驱动工具优先右击“以管理员身份运行”。
3. 打印机开机并使用可传输数据的 USB 线直连电脑；更换 USB 接口、数据线或电脑交叉测试，避免扩展坞。
4. 设备管理器能看到 `USB Printing Support` 或类似 USB 打印支持时，说明电脑已识别 USB 通讯层；驱动列表没有端口时可扫描硬件改动后再安装。
5. 已安装但找不到打印机时，核对队列名称、端口和默认打印机；`USB Printer WT` 只是 USB 识别示例，不等于产品型号。
6. 脱机、暂停或任务卡住时，先确认 Windows 已检测到设备并且实际 USB 端口匹配，再取消“脱机使用打印机/暂停打印”，清空队列，最后重启 Print Spooler 打印服务。
7. 删除旧驱动包、手动添加驱动或改注册表属于高风险步骤；自动回复只做到常规卸载重装，仍失败则转人工技术支持，不提供自行修改注册表的详细步骤。

### 4.8 尺寸、位置、红灯和走纸异常

- 位置偏移、跨标签或打印一半：快递面单按一联/国内 `76×130mm`、二联/海外 `100×150mm` 选择，同时核对当前型号最大纸宽；80mm机型不得选100×150mm。非快递标签才按实际宽高设置，使驱动、实纸和平台模板一致。
- 只有边框没有文字、缺笔画、发灰或不清楚：先用高质量原文件，核对浓度、速度和灰度/水印设置，再清洁打印头并打印测试页。
- 红灯闪烁且缺纸时正确装纸、合盖并等待机器自动识别；纸张可在开机或关机状态装入，不主动建议按走纸键。红灯常亮时依次检查装纸、上盖两侧、传感器、卡纸和纸宽范围，上述正常但连接不稳时再检查 USB。仍红灯则转人工。
- 纸张褶皱、走偏：重新居中装纸，左右导纸器只轻贴纸边而不夹弯纸张，清除折痕、胶屑或异物；换平整合规纸张测试。多批纸都持续褶皱则转人工检查胶辊/机械结构。
- 空白页先确认热敏面、USB/端口和隐藏打印任务，再看自检页或 Windows 测试页；自检页正常而 Windows 测试页空白时重装已确认兼容驱动，自检页也空白时重新确认热敏面，仍空白则转人工检查打印头/硬件。
- 异响或不进纸时停止反复打印，关机后检查/清洁传感器；仍异常转人工检查胶辊或齿轮，不指导拆机。
- 上盖卡扣损坏收集型号、订单和照片后转人工核对配件，不承诺库存或免费补发；拔电后短暂亮灯通常是电容余电，与 USB 无关，持续异常则停止使用并转人工。

### 5.2 自动客服可先处理但要谨慎

- 退货寄回：可说明“需客户在平台申请并按后台地址寄回”，但不要替客户叫快递。
- 运费报销：可提醒保留支付凭证，不支持到付，不要寄顺丰或特快；具体报销转人工。
- 缺数据线：可先安抚并核对订单配件，是否补发/报销必须转人工确认。
- 机器污渍/插头弯：可道歉并询问是否影响使用，小额补偿或退货必须转人工确认。
- 打印头：质保重点是打印头通常按 3 个月口径处理；超过期限或收费必须转人工。

## 7. 禁用话术

- “肯定是机器坏了”，除非自检页/测试页和基础排查已经证明。
- “这个不支持”单句结束；必须说明原因和替代方案。
- “你自己找快递/自己看后台”这种生硬话术。
- “打印头坏了直接寄回”，没有先让客户清理打印头、自检页或确认过保。
- 反复发同一句截图要求，不解释为什么需要这个位置截图。
- 客户已经说清楚问题时，还只问“有什么可以帮您的”。
- 金额、补差价、运费、维修费直接承诺或拒绝。

## 9. 2026-09-21 已确认的平台组件与系列装纸补充

### 9.1 平台打印组件

- 客户明确当前平台后，一次只发送该平台唯一匹配的 Windows 打印组件入口；优先使用当前商家后台、官方帮助中心或已确认的动态下载入口。
- 客户未说明平台时先问当前平台或要打单页面截图，不主动列举其他平台，也不一次发送多个组件链接。
- 组件安装后仍不打印时，先用 Windows 测试页区分机器/驱动和平台组件问题；完全退出并重新启动打印组件，再在平台内重新选择当前打印机。
- 安全软件确实阻止官方安装程序时，可受控短暂停用，安装完成后立即恢复；不允许永久关闭防护，也不得下载第三方 DLL。
- 具体平台入口、错误状态和分层排查以 `confirmed_ecommerce_print_components_2026_09_25_kb.md` 为准。

### 9.2 手机平台打印

- 对客只说明“已确认支持直接手机打印的平台”和“其他平台”，不主动列举不相关平台名称。

- 中国市场只使用“速印通”名称；蓝牙流程为：开启手机蓝牙和 App 权限、打印机开机可配对、在速印通内搜索连接、确认标签预览后打印。

### 9.3 TP612 与 TP518 型结构

- 采用 TP612 型结构的全部机型：上盖紧时按侧面内凹开盖按钮后抬盖；打印头、胶辊、导纸器、纸张传感器和前后纸路可按同一结构族识别。红灯或不识别纸张时先断电清洁传感器区域。
- 采用 TP518 型结构的全部机型：内置卷纸从纸仓居中引出，外置折叠纸从后部进纸口直线送入；纸卷轴、圆形定位片、打印头、胶辊、上下/前置传感器和导纸器可按同一结构族识别。
- 两种结构都要让导纸器轻贴纸边；纸张可在开机或关机状态装入，合盖后等待机器自动识别，不主动建议按走纸键。客户照片/视频与结构示例不一致时先要铭牌照片，不强行套用。

### 9.4 说明书图示清洗后的照片/视频排查规则

- 照片/视频可用于识别结构族、面板类型、前后进纸方向、打印头、胶辊、传感器、导纸器、纸卷轴、圆形定位片、USB/电源接口和外置纸卷架，但不能只凭外壳确定具体型号。
- 采用 TP612 型结构且使用外置大卷纸时，可把兼容纸卷架放在机器后方，让纸张从纸卷上方进入后部进纸口；纸卷架为另购附件，不属于标准包装。
- 走纸键只作为面板部件识别信息保留，不作为装纸、红灯或对位排查中的客户操作建议；连续走纸/跳纸先核对尺寸和间隙，再断电清洁传感器并确认下传感器组件位置。
