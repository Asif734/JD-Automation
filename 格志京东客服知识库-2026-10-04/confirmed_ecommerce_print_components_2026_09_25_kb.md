# 电商平台打印组件已确认知识（2026-09-25）

## 1. 适用范围和总原则

本文件用于中国电商平台 Windows 打印组件的客服检索、安装路由和故障分层，不替代打印机驱动、平台订单/电子面单规则或硬件维修知识。

- 客户只说“打印组件/打单组件/云打印组件”时，先确认具体平台或索要打单页面截图，一次只发送一个匹配入口。
- 优先使用平台当前商家后台、官方帮助中心或经确认的动态下载入口。静态/带版本号的 EXE 可访问，只能证明该地址在复核日可访问，不能证明最新版、数字签名、长期支持或自动更新。
- 正常运行官方安装程序即可；仅在官方说明或权限报错需要时使用管理员权限。
- 安装或更换打印机驱动后，应完全退出并重新启动平台打印组件，在平台内重新选择当前打印机，再打印一张测试单。
- 不永久关闭杀毒软件或防火墙，不下载第三方 DLL。优先验证官方来源/签名和应用级权限；受控短暂停用后必须立即恢复。

## 2. 平台入口和边界


### 2.3 京东

- 官方云打印通过 Windows 组件和本地 WebSocket 通讯；开发文档给出 `ws://127.0.0.1:9113`，端口检查仅供技术排查。
- 旧 HTTP 安装地址会重定向到 HTTPS，不再把 HTTP 地址作为规范入口；从京东商家后台或官方云打印文档进入当前组件。
- `运单未在青龙系统生成` 属于订单/运单业务流程，不是打印机、USB 或打印头故障。检查订单状态、物流/电子面单账号和青龙生成顺序后转平台订单/物流支持。



## 3. 通用故障分层

### 3.1 组件未安装、未启动或本地连接失败

1. 记录平台、完整报错、Windows/浏览器、组件名称和版本。
2. 确认官方组件已安装并正在运行，再重启组件和浏览器页面。
3. 只有平台文档明确本地服务/端口时才检查端口；先识别占用进程，不终止无关进程、不盲目改端口。
4. 组件仍无法启动或反复崩溃时，带日志转平台技术支持，不先判断打印机硬件损坏。

### 3.2 组件内打印机列表为空

1. 在 Windows 中确认当前打印机队列并打印 Windows 测试页。
2. Windows 看不到或测试页失败：先查驱动、USB/端口、数据线和打印机状态。
3. Windows 测试页正常：完全退出并重启组件，刷新平台并重新选择当前打印机。

### 3.3 无效打印机/换驱动后不可用

删除平台中的旧选择，核对当前 Windows 打印机名称，重启组件后重新选择。兼容驱动显示名可能不同，不因名称不同就盲目删除驱动。

### 3.4 任务状态判读

- `打印准备中`：优先查组件连接、登录会话、模板/资源下载和任务日志。
- `渲染完成` 或“成功”但不出纸：优先查选中的 Windows 打印机、离线/暂停队列、驱动、USB/端口和平台特定运行库。
- `打印异常`：必须记录完整错误码/文本，区分模板渲染、订单数据、组件连接和打印输出。
- 一直“打印中”：核对实际是否出纸和 Windows 队列；纸已打印但平台状态不结束，按回调/状态同步问题收集任务编号、时间和日志转平台。

### 3.5 空白、乱码、不完整和偏移

- 空白：先确认热敏面朝打印头、纸张为热敏纸，再比较机器自检/Windows 测试页和平台任务。测试页也空白查纸张/打印头；只有平台空白查模板/渲染。
- 乱码/不完整/重叠：核对驱动和页面尺寸，只清除受影响任务，重启组件；Windows 正常而平台异常时查模板/资源日志。
- 偏移/裁切/尺寸错误：统一平台模板尺寸、Windows 打印首选项和实际纸张；平台组件打印时不要叠加浏览器缩放。常见国内快递面单为 `76×130mm`、海外为 `100×150mm`，但以平台实际模板为准。

### 3.6 模板、资源和业务数据

- 模板/图片下载失败：从官方页面重试，检查网络、登录会话和模板状态，记录失败资源与组件日志，不从未知网站替换资源。
- 模板不存在/未启用、业务数据缺失、无电子面单账号：检查模板 ID/版本、环境、卖家授权、快递/电子面单账号和订单资格，不因该类报错重装打印机驱动。

## 4. 必收集信息

1. 平台名称及商家后台打单页面截图。
2. 完整错误文本/代码和出现步骤。
3. Windows 版本、浏览器、组件名称/版本/来源。
4. 打印机准确型号、Windows 队列名、USB/网络连接。
5. Windows 测试页是否正常。
6. 任务/订单编号、时间和组件日志；对客信息需脱敏。
