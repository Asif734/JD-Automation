## 4. Windows 10/11 安装、端口与队列

### 4.1 安装驱动与识别成功标志

1. 确认 Windows 版本和准确型号，使用对应教程；当前官方 Windows 打印机驱动适用于所有打印机型号的 32 位和 64 位 Windows，不把系统位数作为型号选择或拒绝安装的门槛。驱动名称不必与销售型号逐字相同，但只能使用已确认的兼容驱动族。
2. 确认驱动包来自已验证的官方/售后来源。
3. 可临时退出或关闭杀毒软件，避免拦截安装；安装完成后恢复开启。
4. 打印机开机，使用可传输数据的 USB 线连接电脑；安装期间不拔线。
5. 运行驱动安装文件，按向导完成。
6. 在“设备和打印机/打印机和扫描仪”中确认正确打印机队列；`USB printer WT` 是视频中的 USB 设备识别例子，不把它当成对客型号。
7. 打印一张 Windows 测试页，验证驱动、端口和数据通讯。
8. 安装或更换驱动后，完全退出并重新启动平台打印组件，回到打印页面重新选择当前打印机，再打印测试单。

### 4.2 USB 不识别或手动安装找不到端口

1. 确认打印机开机，USB 线不是纯充电线。
2. 改用电脑其他 USB 接口，再换一根可传输数据的线复测。
3. 在设备管理器中确认是否出现 `USB Printing Support/USB打印支持`或异常 USB 设备，然后扫描检测硬件改动。
4. 若 USB 设备可见但安装程序报“没有对应驱动”，走手动添加本地打印机，选实际 USB 端口和匹配驱动文件。
5. 完全不识别且换口、换线、换电脑后一样，转人工技术检测 USB 接口/主板。

### 4.3 驱动已安装但不打印、脱机、暂停或任务卡住

1. 确认开机、USB 线和纸张正常，并在 Windows 中确认设备已经被检测到。
2. 在打印机属性的“端口”中选择与实际连接一致的 USB 端口；不确定时通过插拔 USB 观察新增/消失端口。
3. 设备已检测且端口匹配后，再打开正确打印机队列，取消“暂停打印”和“脱机使用打印机”。
4. 删除卡住的旧任务；若无法删除，先关闭打印软件，重启 `Print Spooler/打印后台处理程序`。
5. 每次只改一项，用 Windows 测试页复测。

### 4.4 删除、重装与高风险边界

- 先清空队列、关闭打印软件、移除打印机，再从打印服务器属性删除对应驱动和驱动程序包。
- 驱动包被占用时，重启 Print Spooler 后再删除；不组合删除其他打印机的驱动。
- 注册表安装/修复仅在普通安装和手动安装失败后由人工技术处理；自动客服不发注册表修改步骤。

## 5. 尺寸、位置和只有边框没有字

### 5.1 添加自定义尺寸与位置偏移

1. 快递面单不需要测量：国内一联快递面单为 `76×130mm`，二联/海外快递面单为 `100×150mm`；选择前仍须核对机器最大纸宽，80mm机型不得推荐100×150mm。
2. 非快递标签或自定义标签才测量实际宽、高，并在打印机首选项或打印服务器属性中新建相同纸张规格。
3. 在打印软件/平台中选同名规格，使实际纸、预览/模板和驱动三处一致。
4. 先在模板/预览中调边距；预览正常但实体纸整体偏移时，再以 `1–2mm` 小步调边距或水平位置。
5. 纸张居中，导纸器轻贴纸边而不夹弯纸张，每次只改一个方向并测试一张。

### 5.2 只有边框没有字体

1. 先打印 Windows 测试页，确认是驱动还是具体模板/字体问题。
2. 核对机型所属的已确认兼容驱动族，不使用 Windows 自动识别的无关驱动；TP731S 可用 TP731HS 或 TP874H，TP874H 族已确认覆盖 TP733、TP732、TP731、JPW830、JPW850，TP730G 族已确认覆盖 TP518、JPW760，不把“等”扩展为未列出的型号。
3. 检查纸张规格、浓度和图形/字体输出。
4. 测试常用中文字体；测试页正常而某文件无字时，优先处理文件/字体/平台组件。
5. 测试页也无字时，删除错误驱动并重装正确驱动。

## 6. 浓度、速度、水印与缺笔画

1. 先确认是热敏纸且热敏面朝向打印头。
2. 关机待打印头冷却，用无尘布/棉签配少量酒精清洁打印头和胶辊，完全干燥后再通电。
3. 打印太淡：逐步提高浓度或灰度阈值；太黑、灰底、糊成一片或有白色杂点：降低浓度和灰度阈值。
4. 文字/条码不清：优先降低速度，再小幅调浓度。
5. 水印/灰度内容不清：调整驱动的水印/灰度相关浓度；普通文字也异常时一并检查整体浓度和速度。
6. 缺笔画：确认纸张方向，清洁打印头，提高浓度、降低速度，再换常用粗一点的字体和其他标签纸测试。
7. 固定位置白线先清洁打印头；若自检/测试页仍在每张的完全相同位置持续出现白线、纵向空白带或一半永远没字，转人工检测打印头。打印头不单独对客销售。
8. 空白页先确认热敏面朝向打印头、USB/端口和隐藏打印任务，再打印机器自检页或 Windows 测试页；自检页正常而 Windows 测试页空白时重装已确认兼容驱动，自检页也空白时重新确认热敏面，仍空白则转人工检查打印头/硬件。
9. 上盖两侧必须同时完全压紧；合盖不平会造成虚印、缺印或位置不稳，先正确合盖再调整浓度或判断硬件。

## 7. 红灯、上盖、传感器、起皱与走偏

### 7.1 ERROR 红灯

1. 红灯闪烁并且缺纸时，先正确装入热敏纸并合盖，等待机器自动识别纸张；纸张可在开机或关机状态装入，不主动建议按走纸键。红灯常亮时再按以下步骤检查。
2. 确认上盖完全压紧，两侧卡扣都已锁住。
3. 确认标签间隙/黑标经过传感器，导纸器贴合纸边但不夹弯纸张。
4. 仍亮红灯时，关机断电，清理进纸通道、胶粘物和纸屑；完全干燥后重新装纸、合盖并等待自动识别。
5. 窄纸还要核对是否在当前型号支持的纸宽范围内；装纸、上盖、传感器和纸宽都正常但连接不稳定时，再检查 USB。
6. 确认上述项目后仍持续红灯/不走纸，转人工检测。

### 7.2 打印起皱、斜行或走偏

1. 停止打印并关机，取出已起皱的纸，不反向猛拉。
2. 检查纸卷/纸叠两侧受力是否一致，纸张是否居中，导纸器只贴纸边而不挤压纸张。
3. 清理胶辊和进纸通道的胶水、灰尘、纸屑，检查上盖两侧卡扣压力是否一致。
4. 用平整、尺寸/间隙匹配的新纸只走一张测试。
5. 仍在同一侧起皱或斜行，或上盖/卡扣/胶辊有损伤，转人工检测，不指导拆机。

### 7.3 异响、不进纸、卡扣和断电余电

- 异响或不进纸可能与胶辊、齿轮打滑或传感器有关；停止反复打印，关机后检查和清洁传感器，仍异常转人工维修，不指导拆机。
- 上盖卡扣/连接件损坏时，收集型号、订单和损坏照片，转人工核对配件；不承诺一定有货或免费补发。
- 拔掉电源后指示灯短暂保持点亮通常是电容余电，与 USB 无关；持续较长时间仍有异常供电表现时停止使用并转人工。

## 11. TP612 型结构和 TP518 型结构硬件范围

### 11.1 TP612 型结构的上盖、纸张传感器和内部结构

- 采用 TP612 型结构的全部机型，其外观、上盖、纸张传感器、打印头、胶辊、导纸器、前后进出纸路径和面板位置可按同一结构族识别；不得只因外观相似就推断具体型号。
- 上盖较紧时，按住机身侧面的内凹开盖按钮后向上抬起上盖；不要直接撬盖或暴力拉扯。
- 红灯、无法识别纸张或走纸异常时，先关机断电、取出纸张，清理下部进纸通道中央的纸张传感器区域，完全干燥后重新装纸、合盖并等待机器自动识别；不主动建议按走纸键。
- 客户照片或视频中的外观、面板或内部结构与 TP612 型结构示例不一致时，停止套用该结构族知识并请求机身铭牌/型号照片。

### 11.2 TP518 型结构的部件识别和装纸

- 采用 TP518 型结构的全部机型，其打印头、打印头支架、胶辊、上下/前置传感器、左右导纸器、纸卷轴、纸卷定位片、后部折叠纸入口和前部出纸口可按同一结构族识别。
- 采用 TP518 型结构且面板相同的机型可识别为绿色联机灯、红色错误灯、三角形功能/走纸键和电源键；面板不同不得照搬按键结论。
- 内置卷纸：可在开机或关机状态打开上盖，把纸卷装在纸轴/纸仓中，热敏面朝向打印头，纸张从左右导纸器中间直线引出，合盖后等待机器自动识别纸张。
- 外置折叠纸：可在开机或关机状态从机器后部进纸口把纸张直线送入，穿过左右导纸器并居中，合盖后等待机器自动识别纸张。
- 导纸器只贴合纸边，不夹弯纸张；纸张歪斜、起皱或红灯时重新居中装纸后再测试。

### 11.3 自检页和其他硬件图片

- 自检页可用于核对 USB/PID、蓝牙名称、固件和打印头输出状态，但客服不主动提供按走纸键的自检操作；需要自检页且没有其他已确认入口时转人工按具体型号指导。

- 打印头位置和整机内部结构图片仅作外观匹配参考；未确认具体系列前不得声明所有热敏机结构完全相同。

## 13. 2026-09-23 旧说明书清洗后的结构与图像知识

### 13.1 证据与适用边界

- 旧说明书只作为结构、部件、纸路和历史规格的证据，不把整份说明书直接导入知识库。
- `510.pdf` 与 `518(1).pdf` 内容和 SHA-256 完全相同；其结构图按 TP518 型结构族使用，不把文件名当成具体型号证明。
- `TP732(1).pdf` 与 `733-730-736说明书.pdf` 内容和 SHA-256 完全相同，封面实际标注 TP733/TP730/TP736；不得作为 TP732 证据。其结构图按用户确认的 TP612 型结构族使用。

### 13.2 TP518 型结构的视觉特征

### 13.3 TP612 型结构的视觉特征

### 13.5 走纸、纸卷和排障补充

- 走纸键只作为面板部件识别信息保留，不作为装纸、红灯或对位排查中的客户操作建议；纸张装好合盖后等待机器自动识别。
- TP518 型结构和 TP612 型结构的旧资料记录纸卷外径约 120mm；TP630 旧资料记录内部纸卷外径约 100mm。该值用于结构/容量判断，不覆盖当前具体 SKU 纸仓规则。
- 标签厚度超过约 0.22mm 可能降低打印质量；仅作为这些旧结构族的历史排障参考，不作为所有热敏机通用硬上限。
- 跳纸除尺寸/间隙错误外，还可能是传感器有异物或下传感器组件错位；断电清洁并确认位置，不能恢复时转人工，不指导拆机。
- 黑色/深色标签出现固定灰线时先清洁打印头和胶辊；自检/测试页仍在同一位置异常时转人工检查。
