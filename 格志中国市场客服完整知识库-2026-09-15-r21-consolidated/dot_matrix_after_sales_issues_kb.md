# 针打售后问题知识库

## 1. 总原则

- 第一目标是先弄清楚客户真实问题，再给步骤；不要只发通用截图、驱动链接或欢迎语。
- 客户要投诉、退货、寄修、收费、维修进度时，先解决机器/订单问题，再谈规则。
- 针打问题不要套用热敏机话术，例如“清理打印头”这类热敏机快捷语不能用于针式打印机。
- 同一个现象可能来自驱动、端口、纸张、色带、感应器、软件模板或硬件，必须按顺序排查。
- 客户提供了图片、视频、型号、购买日期、物流单号时，要先利用已有信息，不要反复要求客户重新说明。
- 超过两轮仍不能定位，或涉及金额、寄修、过保收费、投诉，应转人工/组长并附带摘要。

## 3. 驱动、端口、任务类问题

### 3.1 不打印/脱机/打印任务卡住

典型信号：

- 客户说“不打印”“打印不出来”“状态显示正在打印但机器不动”。
- 驱动状态显示 `脱机`、`暂停`、任务栏一直有任务。
- 测试页失败、打印服务无法开启、删除驱动失败。

排查顺序：

1. 先看机器是否正确放纸，机器自检/测试页能否打印。
2. 先重新插紧 USB 数据线或更换电脑 USB 接口，再查看 `设备与打印机`/设备管理器是否检测到常见的 `AT32` 设备。
3. 设备已经被检测到后，确认已安装驱动的端口与实际连接匹配。物理连接和端口恢复时，驱动通常会自动上线。
4. 再看驱动状态是否 `暂停`、`脱机` 或卡任务；暂停就取消暂停。
5. 删除打印队列和隐形任务。需要深度清理时：右击 Windows 左下角开始键 → 运行 → 输入 `SPOOL` → 打开 `printers` 文件夹 → 删除里面的隐藏任务；同时清空所有待处理打印任务，再重新发送一份新任务测试。
6. 重启打印服务后再删除或重装驱动。
7. 电脑同时有多个驱动队列时，先使用可用在线驱动并核对连接、端口、队列和隐藏任务。只有仍确认存在持续的重复或错误驱动故障时，才删除错误项或 `printdriver` 并用官方安装包重装；不得仅因另一个匹配队列离线就全部删除。
8. 仍不行，按硬件/接口故障处理，转人工或寄回检测。

持续出空白纸时还要检查文档是否包含额外空白页、打印区域是否正确，以及 USB 数据线是否松动。USB 单一连接版本没有本机自检功能，不要把自检作为必做步骤。

如果正常走纸、打印头也能移动，但没有针击打声且纸上没有内容：先检查 USB 连接，清空打印队列和 `SPOOL/printers` 隐藏打印任务，只重新发送一份任务。如果打印头仍能移动但没有针击打声，判定为打印头故障，通过人工客服申请维修。

模板：

> 亲，请先重新插紧 USB 数据线或换一个电脑 USB 接口，然后拍一下设备页面，看是否出现 AT32 设备。设备能识别后再核对驱动端口；如果仍显示脱机/暂停或任务卡住，再清理队列和隐形任务。

如果视频表现为打印头动一下、停一下、再继续，优先按隐藏任务处理，不要归入“打印速度慢”：

> 亲，请右击电脑左下角开始键，选择“运行”，输入 `SPOOL`，打开 `printers` 文件夹，把里面的隐藏任务删除；再清空当前所有待打印任务，重新发送一份新任务测试。

### 3.2 打印测试页失败

处理：

- 先确认当前为 Windows 针式打印机场景，并检查驱动端口是否对应实体打印机。
- 在针式打印机范围内，不同型号驱动可能通用，例如 AK890/TG890 或 AK890/TD630；安装后必须打印测试页验证。
- 上述驱动通用结论仅限针式打印机，不适用于热敏机、标签机或考勤机。
- 驱动里要有适合当前纸张的规格。
- 可手动安装或通过注册表/驱动配置重新安装。
- 提示缺少 `.NET` 时，普通情况先安装 `.NET 4.8` 后再装驱动。Windows 7 也可手动安装打印机驱动，该手动路线不需要升级 `.NET`。

模板：

> 测试页失败一般先看驱动是否匹配。请发一下驱动名称、机器型号和 Windows 版本。如果提示缺少 .NET，通常安装 .NET 4.8；Windows 7 也可手动安装打印机驱动，手动路线不需要升级 .NET。

### 3.3 云打印/软件组件问题

典型信号：

- 软件提示缺少云打印组件。
- WPS/软件里打印不了，但测试页可以打印。
- 杀毒软件拦截组件安装。

规则：

- 店铺机器不支持云打印时，要让客户选择本地打印机。
- 第三方开单 App 直接打印出现空白时，不建议客户购买云盒；云盒仍可能因兼容性出现空白或乱码。建议在原 App 中导出/保存文件，再用速印通打开并打印。
- 测试页正常但软件不能打，优先判断为软件设置/组件/登录问题。
- 软件组件安装失败，可提醒退出杀毒软件、允许安装；仍不行找软件方。

模板：

> 如果测试页可以打印，机器和驱动大概率是正常的。请您在软件打印页面选择“本地打印机/当前驱动”，不要选云打印；如果软件提示缺少组件，可以先退出杀毒软件后允许安装。仍无法安装时，需要软件方协助处理组件。

## 4. 进纸、感应器、放纸问题

### 4.1 吸纸异常/只出白纸/连续出纸

典型信号：

- A4 能打印，收据纸无法吸入。
- 放纸就出白纸、点击打印才出白纸、连续出白纸。
- 后进纸连打只打一张，后面不打。
- 机器前后进纸方向与实际放纸方向不一致。

排查顺序：

1. 先判断前进纸还是后进纸，清理对应感应器，不能清错位置。
2. 后进纸问题清理后进纸感应器，前进纸问题清理前进纸感应器。
3. 前进纸不自动吸入时不需要按进纸键，也不强推纸张；取出纸张和色带，关机后用少量酒精清洁纸张感应器，完全干燥后重新装回测试。
4. 感应器附近两个位置都要清理。
5. 黑底收据纸可能被光感感应器误判，可垫一张 A4 纸一起吸入。
6. 强光直射会干扰光感感应器，提醒避开太阳光直射。
7. 仍异常时打开盖子拍吸纸位置视频，必要时寄回检测。

前进纸一次吸入半张或更多纸，或打印一张后又多走出大量纸时，优先判断前进纸感应器异常；后进纸出现同类现象时检查后进纸感应器。取出纸张并关机，用湿纸巾或酒精轻轻清洁对应传感器，待酒精完全挥发后重新装纸测试。

如果视频同时出现“缺纸红灯亮、后进纸按进纸键不送纸、打印头只轻微移动后回位”，按组合故障处理：重启机器，取下色带，开机时只观察打印头能否自动移动并检查周围是否有异物；后进纸仍不送纸时清理后进纸感应器，再测试前进纸。仍无效转人工维修。

模板：

> 亲，这个更像进纸/感应器识别问题。麻烦先确认您是前面放纸还是后面放纸，我再告诉您清理对应感应器的位置。清理后重启机器重新放纸试一下；如果是黑底收据纸，可以垫一张 A4 纸一起进纸测试。

### 4.2 打印一张后不打印/半停/反向打印

处理：

- 清理后进纸感应器。
- 删除隐形任务。
- 检查端口和 USB 接口。
- 检查驱动是否设置固定页面高度。
- 修改固定页高或纸张孔数并保存后，先完全关闭并重新打开打印软件，再取出纸张并按新设置正确重新装入后测试。
- 如果半停后自动打印，重点看隐形任务和感应器。

模板：

> 打印一张后停住，常见是后进纸感应器、隐形任务或端口问题。我们先清理后进纸感应器，再删除打印队列/隐形任务，然后换 USB 口测试；如果仍然只打一张，我帮您转技术继续看端口和硬件。

### 4.3 放纸倾斜/卡纸/纸张退出异常

处理：

- 打开盖子拍放纸过程视频。
- 卡纸时优先把纸厚扳手调到最高的第 6 档，可改善进纸、减少卡纸并保护色带和打印头。该结构的调法为右手拇指把扳手向右按住，再向上推。
- 取出色带或去掉色带卡扣透明胶片，排除色带干扰。
- 卡住退不出时，先按进纸/退纸看能否退出；色带缠绕严重可能需要剪断色带并更换。
- 前进纸宽度明显过窄时容易走斜；建议使用 `100–241 mm` 宽纸张，放平并让导纸器贴合纸边。
- 打印机内白色宽排线弯曲属于正常结构，不要调整。如果同时卡纸，将纸厚扳手调到最高档，取下色带后用多联纸打印并检查第二联；第二联出现水平横线或仍然卡纸时，返厂维修。
- 多联纸正常应连接成一整套。如有分层、错位、卷曲或折叠，先更换完整纸套，或把整套对齐后重新放置，再判断打印机。

模板：

> 麻烦您打开前盖拍一段放纸和吸纸的视频，我看一下是哪边卡住或倾斜。先把扳手调到最高，并取出色带盒测试一次；如果取出色带后正常，就优先处理色带/胶片干扰。

## 5. 位置、版式、纸张规格问题

### 5.1 打印偏左/整体靠左

常见处理：

- 先确认打印软件模板、驱动纸张规格和实物纸张一致。
- 进入 `设备和打印机 -> 右击对应驱动 -> 打印首选项 -> Configure`。
- 使用 `Horizontal adjustment` 按 1mm 小幅调整整页左右位置。
- 同时检查放纸滑块位置和文档边距。只有内容压到左侧拖纸孔或涉及左侧空白页处理时，才检查 `删除左边空白页/delete left blank page`。

模板：

> 亲，请先确认模板和驱动纸张规格与实物一致，再进入设备与打印机，右击当前针打驱动，打开打印首选项/Configure，用 Horizontal adjustment 每次按1mm小幅调整；保存后完全关闭并重新打开打印软件，再取出纸张并正确重新装入测试。

### 5.2 右边/左边/顶部打印不全

排查：

1. 先看打印预览是否完整。
2. 检查驱动和预览中的纸张规格、方向是否一致。
3. 右边打印不全，常用处理是驱动里选中 `删除左边空白`，必要时换 JMS 或缩放驱动。
4. 左边打印不全，可能是驱动不对或左右偏移，先换驱动/调空白选项。
5. 顶部打印不全，先看吸纸位置是否正确，再看纸张规格和固定页面高度。
6. 文档本身超出机器打印范围时，需要调整软件模板边距或找软件方。

模板：

> 先麻烦您看一下打印预览是不是完整。如果预览完整但右边打不全，我们再检查驱动纸张规格和“删除左边空白”选项；如果预览本身也不完整，需要先在软件里调整纸张大小、方向和边距。

### 5.3 起始位置、顶部空白、页边距过大

处理：

- 检查吸纸位置是否正确。
- 推荐页边距先设为左右 `0.3`、上下 `0.5`，页眉页脚设为 `0`。
- 客户要求内容居中时，勾选水平居中和垂直居中；如果只需要偏移校准，则分别调整水平和垂直偏移。
- 驱动里设置与实际纸张一致的纸张规格和固定页面高度。
- 精确路径：`控制面板 -> 硬件和声音 -> 设备和打印机 -> 右击对应打印机 -> 打印首选项 -> Layout -> 高级 -> 纸张/输出 -> 纸张规格`；选定纸型并确定后，进入 `Configure`，选择并勾选对应的固定页面高度。后进连续纸时取消勾选`删除页面底部空白`、`删除左边空白页`、`删除页面顶部空白`、`将位图图像输出到计算机`和`纸边孔长计算`，单向打印保持原设置；点击`导入`后再点击`确定`。保存后必须完全关闭并重新打开打印软件，再取出纸张并正确重新装入。
- 删除顶部和底部空白选项根据现象勾选/取消。
- 如果进纸方向、纸张规格、固定页高、页边距和装纸位置都正确，但仍然从页面中间开始，关机后清洁对应进纸方向的纸张感应器，完全干燥后重新装纸测试。

模板：

> 起始位置不对要同时看吸纸和页面设置。请先把页眉页脚设为0，左右边距设0.3、上下边距设0.5；需要居中时勾选水平居中和垂直居中。

### 5.4 横向打印/方向不对/纸张规格不匹配

处理：

- 默认使用纵向（Portrait）；只有客户明确需要横向，或文档/预览确实为横向时，才在文档和驱动中一致选择横向（Landscape）。
- 老驱动无法横向时，换最新 JMS 驱动。
- JMS 首选项里可选择 `90度横向打印`。
- 需要创建自定义纸张时，给创建纸张和选择纸张两套步骤。

模板：

> 方向不对先看两个地方：软件预览里的方向，以及驱动首选项里的纸张方向。如果文档是横向但驱动不支持，可以换 JMS 驱动，并在首选项里选择 90 度横向打印。

### 5.5 预印表格双重打印

- 照片清楚时可直接识别预印表格纸；看不清时只确认一次是空白纸还是预印表格纸。
- 先检查同一张纸是否被重复执行了两次打印。
- 预印单据上只设置并打印可变数据，不要把表格线和固定文字再打一次。
- 先匹配实物纸张规格与进纸方式，再调整水平和垂直偏移。
- 需要打印完整表格和固定文字时，应使用空白纸。

### 5.6 前后进纸正常位置/打印后出纸过多

- 后进连续纸待机时，前出纸口只露出一小段窄纸边属正常；明显露出更多则属异常。
- 前进单页纸时，纸张前端到达机内钢杆处属正常；前盖关闭时，约有 `5厘米` 被吸入。明显超过该位置则属异常。
- 常见连续纸实际纸宽约 `241mm`，驱动预设宽度为 `240mm`，不得混为同一数值。
- `holes 22/3` 表示22除以3，约 `7⅓` 个孔位间隔，不是22或23孔。
- 后进出纸诊断基准：三等分1页约 `7⅓`、2页约 `14–15`、3页约 `22` 个孔位间隔；二等分1页约 `11` 个孔位间隔。
- 出纸明显过多时，先使软件页面大小、驱动纸张大小和 `Fixed page height` 一致，并重新正确装纸。正确时会自动把分页线送到可撕纸位置；只有小偏差时，再用 `tear-off position` 每次 `2mm` 微调。

## 6. 打印效果问题

### 6.1 打印重影/竖线不直

主要原因：

- JM 后缀驱动开启了双向打印。
- 驱动版本不合适。
- 只有文字出现清晰的横向双轮廓或竖线横向错位时才按本节处理。整体发灰、模糊或低质量PDF/图片形成的叠影，应改用高质量原文件并降低Windows灰度阈值或手机对比度，与单向/双向打印无关。

处理：

- 检查驱动名称是否为 JM。
- 在打印首选项的 `Configure` 中勾选 `One-way printing/单向打印`。
- 或直接安装/更换 JMS 驱动。
- 如果除了横向重影还出现固定、连续并贯穿页面的横向黑线，可能是打印针卡在伸出位置；应停止打印并转人工检查打印头，不再按普通双向设置继续排查。
- 如果是水平拖墨或划痕，但尚不能确定为固定硬件黑线，先关机断电、取下色带，清理打印头和支架周围异物；再不安装色带使用多联纸测试。明显划痕仍在时，按打印针无法回缩转打印头维修/更换。

模板：

> 重影或竖线不直通常和双向打印/驱动有关。请在打印首选项的 Configure 中勾选 One-way printing/单向打印并测试；仍不行再检查驱动版本。若同时有固定连续横向黑线，请停止打印并转人工维修。

### 6.2 打印乱码/打印错乱

常见原因：

- 隐形任务未删除。
- 端口错误。
- 驱动不匹配或电脑里有错误驱动。
- USB 数据线或接口松动。
- 操作系统不兼容；Mac 使用了错误驱动。
- 不兼容的第三方手机 App 直接打印；此时应先导出/保存文件，再用速印通打开打印。
- 使用了不兼容的云盒。
- 色带/胶片干扰或机器失步。

处理顺序：

1. 删除打印队列和隐形任务。
2. 检查端口，换接口或数据线。
3. 检查驱动名称，彻底删除错误驱动后重装。
4. 取出色带，不安装色带直接用多联纸打印。
5. 如接有云盒，移除后直连测试；不建议用云盒解决乱码或空白。
6. 仍乱码/错位，寄回检测。

路由原则：只选择客户证据所支持的隐藏任务、USB/端口、第三方手机 App 或 Mac 驱动分支，不把所有步骤一次性堆给客户。

### 6.2A 同时自动关机且不进纸

- 将两个症状拆分。关机分支先换一个已知正常的墙插电源座，仍关机则转人工维修。
- 不进纸分支先从前方正确插入纸张，仍不自动吸入时，关机后清洁前进纸纸张感应器。
- 该组合症状不需要拔 USB，也不需要按进纸键。

模板：

> 乱码先按顺序排查：清理打印任务和隐形任务，再看端口是否正确，然后确认驱动是否匹配。麻烦先发驱动名称和端口截图；如果清理和重装后仍乱码，就需要进一步检测机器。

固定位置连续出现圆圈或“8”字符时，不按普通数据乱码处理，优先判断打印头卡住。关机取下色带，检查打印头下方和导轨异物，再开机只观察打印头能否自动左右移动一次；仍不能移动时转人工维修。USB 单一连接版本不要求执行本机自检。

### 6.3 打印错位/失步/压缩

判断：

- 取出色带或去掉色带卡扣透明胶片后直接打印。
- 扳手调到最高。
- 如果不装色带也错位/压缩，多数要寄回检测。
- 文档压缩也可能是进纸马达问题。

模板：

> 错位/失步我们先排除色带干扰。请先取出色带盒或去掉透明胶片，把扳手调到最高，再用多联纸直接打印测试。如果不装色带仍然错位，就需要寄回检测。

### 6.4 打印不清楚/缺针/漏针/白条

排查：

- 看打印样张是否有固定白线、笔画缺失、横线不全。
- 一般缺笔画或不确定是否固定缺失时，先取下色带，撕掉色带上的透明保护膜，正确重新安装并测试；保护膜未取下不能直接判断打印头缺针。
- 图片清晰显示多条竖向笔画在同一高度出现一致的水平白线时，直接判定打印头针断裂/缺针并申请返厂维修，不按双向打印重影处理。只有线条不清晰或不固定时，才取下色带，不安装色带，用多联纸打印并查看第二联。
- “局部笔画缺失、字体不清楚”如果从样张能看出缺失位置固定，也按上述固定白线流程处理；如果无法确认是否固定，先检查色带透明保护膜和安装状态。
- 扳手可适当调低，增强压力。
- 驱动 `打印首选项 -> Configure` 里调整 `Density/阈值`；`DPI/打印质量` 也会影响深浅和清晰度。
- 手机打印可调高对比度，例如对比度提高到约 210。
- 多处白色细线、缺针/漏针、打印头不动，转售后检测。
- 非固定或不明确的缺笔画，重新安装色带后仍在完全相同位置缺失，才判断打印头针可能损坏并转售后。

模板：

> 打印不清楚先看是整体偏淡，还是某些笔画/横线缺失。整体偏淡可以调低扳手、调高打印质量或阀值；如果是固定位置缺针、白线或打印头不动，就可能是打印头问题，需要售后检测。

### 6.5 印记太浓/太淡

处理：

- 驱动阀值越大通常越浓，越小越淡。
- 印记太浓可把阀值调低，例如先试 `160` 左右。
- 印记太淡可调高打印质量/阀值，或检查色带是否干、是否原装。

模板：

> 如果印记偏浓，可以先在驱动里把阀值调低，例如先试 160 左右；如果偏淡，就适当调高打印质量或阀值，同时检查色带是否正常。

### 6.6 表格线太粗、图片网点或背景实黑

- 表格线太粗：优先把模板边框改细，同时降低 Density/灰度阈值并调高纸厚扳手。
- 图片出现大量网点：降低对比度和灰度阈值，优先改用原始 PDF/Excel。
- 整行打印成实黑：检查并删除单元格或图片背景色。

## 7. 色带、耗材和结构件

高频规则：

- 色带缠绕：先取出色带盒，按进纸/退纸尝试退出；安装时保持色带平直、不能扭转。色带已撕裂、起白点或扭转时，先取下色带，不安装色带用多联纸打印并查看第二联；第二联文字中没有水平横线，说明打印头正常，更换新款针式打印机通用色带即可；考勤机和未确认老款不套用。
- 视频显示后进纸按走纸键后纸张歪斜时，先把纸厚扳手调到最高位置并重新对齐装纸；此画面不主动判断为收带齿轮打滑或建议更换色带。
- 色带透明胶片：很多错位、压缩、白条、印记异常要先去掉色带卡扣透明胶片。
- 新机器色带坏：可提醒扳手调到最高，符合条件时补发色带。
- 色带没用几次没墨：询问订单时间；色带长时间不用可能变干，建议定期打印。
- 型号买错：明确指出正确型号，例如 001/002 不可混用。
- 经常打坏色带：检查打印头是否异常。

模板：

> 亲，色带问题我先帮您判断是安装干扰还是耗材异常。请先把扳手调到最高，检查色带卡扣透明胶片是否取下；如果色带缠绕或断裂，拍照给我，我帮您判断是否需要更换或补发。

## 8. 维修、寄修、投诉和费用

### 8.1 维修查询

规则：

- 不要只问“哪里有问题”，要先看前面记录和售后状态。
- 查询维修进度要看客户寄回物流是否登记。
- 我们寄给客户的单号没有物流信息时，要查系统发出时间：
  - 刚修好未揽收：说明待揽收。
  - 时间太久：超过约 6 个月物流可能查不到。
- 防止给错维修单号或二次维修漏登记。
- 维修签收后，应登记并转维修群/维修流程。

模板：

> 亲，我先帮您查维修登记和物流状态。请稍等，我会核对寄回物流、是否已签收、是否已登记维修；如果是我们寄出的维修件，也会确认是否已揽收，避免单号或登记漏掉。

### 8.2 寄回检测条件

需要寄回或人工售后判断的情况：

- 不安装色带直接打印仍错位、失步、压缩或乱码。
- 端口、数据线、电脑都换过仍无法识别。
- 清理感应器后仍持续出白纸、吸纸异常或半停。
- 打印头不动、固定缺针、漏针、多处白线。
- 机器不开机，电源插座排除后仍不开机。
- 过保收费、二次维修、客户投诉、退款/换货争议。

模板：

> 如果按上面步骤排查后仍一样，就可能不是设置问题，需要寄回检测。我们会先登记机器型号、故障现象、已排查步骤和订单售后状态，再由人工售后确认寄修方式、费用和预计时间。

### 8.3 针式打印机不开机

- 更换一个确认正常工作的电源插座测试。
- 长按电源按钮尝试开机。
- 如果仍然无法开机，转人工客服申请维修。
- 不提供关机静置、检查多条线缆或其他扩展排障步骤。
- 客户只询问电源按钮位置时，可以单独回答按钮位置，但不要把该说明加入不开机排障回复。

模板：

> 亲，请先更换一个正常工作的电源插座测试，然后长按电源按钮尝试开机。如果仍然无法开机，请联系人工客服申请维修。

### 8.4 纸张已就位但点击打印无反应

如果视频确认纸张位置正确且缺纸红灯未亮，不要重复要求客户重新放纸：

1. 先打印 Windows 测试页。
2. 测试页不打印时，把 USB 数据线换到电脑另一个 USB 接口后重试。
3. 仍不打印时，核对设备对应端口和打印机驱动端口是否一致。

模板：

> 从视频看纸张已经放好，缺纸红灯也没有亮。请先打印一张 Windows 测试页；如果测试页也不打印，把 USB 线换到电脑另一个 USB 口再试。仍无反应时，再核对设备端口和打印机驱动端口是否一致。

### 8.3 过保收费

规则：

- 过保维修可收费，但要说明依据和检测后确认。
- 不要只报一个数字，必须说明保修状态、费用原因、是否客户确认后维修。
- 过保机器维修通常不承诺优惠。

模板：

> 亲，我先帮您确认保修状态。若机器已过保，维修可能会产生检测/维修费用，具体以售后检测结果为准；确认费用前不会让您不清楚就维修，我会把费用原因和处理方案说明清楚。

### 8.4 快递和承诺风险

禁止：

- 客户要求发顺丰时直接回复“好的”，容易产生纠纷。
- 没核对售后规则就承诺报销运费。
- 维修刚寄回又坏时说“没有配件”，应先检查记录和二次维修规则。

客户退货但没有原包装时，指导使用结实替代包装和足够缓冲材料，确保机器在箱内不会晃动。无需特别要求固定打印头，也不重复说明显而易见的拔线步骤。包装费用不由店铺承担；只有客户询问时再说明，并以平台售后规则为准。

安全回复：

> 快递方式我先帮您核对仓库和售后规则，不能直接乱承诺。确认可发的快递、运费规则和时效后，我再给您明确答复。

## 9. 软件/系统兼容

- 某些型号不支持 Mac，必须看机器标签/型号后再答复。
- 测试页正常但 WPS 打不了，可尝试登录账号、重新安装 WPS 或咨询软件方。
- 预览都不全、页脚/页码/模板无法保存，通常是软件模板问题。
- Windows 测试页正常时，电脑端通常可从任何能够调用已安装 Windows 打印机的业务软件打印；在业务软件中选择本机驱动或将其设为默认打印机。我们不提供第三方业务软件本身。
- 设备管理器可能显示 `AT32 Printer FSS mode`；TD630/TD630G 也可能显示 `USB Composite Device`。硬件名称不必等于型号；无法打印先换 USB 口，不得仅凭该名称判断固件故障。
- `AT32 Printer FSS mode`与“未知USB设备/设备描述符请求失败”必须区分：后者表示USB识别或连接不稳定，先换USB接口，再换USB数据线。
- 当前针式打印机支持的纸张总厚度上限统一为 `0.45mm`。客户询问特殊硬纸板时，按总厚度判断，不得承诺超过上限。

模板：

> 亲，我先看机器型号是否支持您的系统。有些针打型号不支持 Mac 或云打印；如果测试页能打但软件里不能打，通常是软件模板或组件设置问题，我们可以先确认驱动正常，再让软件方调整模板。

## 10. 不合适处理方式

- 没看前面记录，重复问客户已提供的信息。
- 客户问具体问题，只回复“您好/有什么可以帮到您”。
- 用热敏机的清理打印头话术处理针式打印机。
- 客户给了图片/视频却不看细节，乱发截图。
- 不确认机型、纸张、驱动，就让客户远程或寄修。
- 一直要求订单号，但客户已经提供物流面单或足够信息。
- 维修查询只说“多久修好”，不查是否签收、登记、漏登。
- 涉及顺丰、运费、过保收费、补发、退换修时随口承诺。
