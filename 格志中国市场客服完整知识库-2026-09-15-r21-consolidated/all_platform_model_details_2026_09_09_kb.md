# 全平台型号资料统一治理知识库（2026-09-09）

## 1. 使用边界

- 对客回答只能使用本文件及其同步后的主题知识、正式 RAG 卡片和检索映射；不得补全工作簿未确认的设置、按钮、范围、价格、库存或赠品。
- 型号、系统、设备类型、连接方式、平台、纸宽或订单时间会改变答案时，只确认一个最关键的信息后再给唯一对应的答复。
- 内部型号关系、内部售后例外、内部审批条件和内部来源说明不得对客户披露。
- `Legacy` 只表示历史型号，不等同于当前在售；`Discontinued` 型号只能处理历史售后或配件查询，不得用于售前推荐。

- 其他停产或很老的型号可保留历史售后/配件兼容信息，但受理维修前必须先由人工实时确认是否有配件；不得先承诺可修或给固定寄修地址。

### 2.4 外壳 Logo 与型号识别

- 部分新外壳不一定在正面显示醒目的厂商 Logo，当前产品也可能按打印宽度分类，但准确型号仍以机身或标签/铭牌信息为准。
- 不得编造具体型号，也不得因正面没有 Logo 就否定产品真伪。只有型号会改变操作或兼容结论时，才请客户拍摄标签/铭牌。

## 3. TD630 / TD630G 对客连接规则

| 型号 | 售前展示 | 手机打印 | Windows 电脑 | macOS 电脑 |
|---|---|---|---|---|
| TD630 | 蓝牙 + USB | 速印通支持蓝牙或 2.4GHz Wi-Fi；Wi-Fi 时手机与打印机需在同一网络 | 仅 USB；不支持电脑 Wi-Fi，也不支持电脑蓝牙 | USB |
| TD630G | 蓝牙 + Wi-Fi + USB | 速印通支持蓝牙或 2.4GHz Wi-Fi | USB 或同一 2.4GHz 局域网 Wi-Fi；不支持电脑蓝牙 | 仅 USB，不支持 Mac 无线打印 |

- 售前推荐必须按商品页的客户可见型号描述：TD630 按“蓝牙 + USB”，TD630G 按“蓝牙 + Wi-Fi + USB”。
- 客户询问 TD630 手机连接时，可以提供蓝牙或 Wi-Fi 两种速印通路径；客户询问 TD630 电脑无线打印时，明确仅支持 USB，不发送 TD630G 的 Windows Wi-Fi 端口教程。
- 不向客户解释两个型号的内部硬件、内部路由或内部命名关系。

## 4. 热敏机系统、纸张与平台边界

### 4.1 macOS USB

- TP870、TP876：不支持 macOS；需要 macOS USB 时推荐相应 PLUS 型号。
- TP870PLUS、TP876PLUS、TP874、TP874S：支持 macOS USB；不据此承诺电脑 Wi-Fi。
- 老批次兼容 SKU 如需 Windows 固件处理，属于例外，转人工确认。

### 4.2 已确认纸宽

| 型号 | 可打印纸宽与边界 |
|---|---|
| GZP510 | 30–100mm；已记录长度 30–300mm；内置纸仓，卷径约 12cm |
| GZP810S、GZP820S、GZP860、GZP860S、JPW500、JPW830、JPW850PLUS、TP731、TP732、TP732S、TP874、TP874S | 30–80mm；具体纸仓/卷径仍按型号或 SKU |
| GZP820 | 30–100mm；已记录长度 30–300mm；无内置纸仓，后部进纸 |
| JPW760S、TP510、TP518、TP730、TP730S、TP876 | 30–100mm；可装最高约 104mm 宽介质；纸仓边界按型号 |
| TP870、TP870PLUS | 30–100mm；纸仓以所选 SKU 为准 |
| TP876PLUS | 80mm SKU 为 30–80mm；104mm SKU 为 30–100mm；必须核对购买选项 |
| TP630 | 30–80mm |

- 纸宽是主要限制；除表内明确长度范围外，不编造统一长度上限。
- 旧资料中的 `40–80mm` 或 `40–100/104mm` 泛化口径由本表的 `30–80mm`、`30–100mm` 与精确 SKU 规则取代。
- 热敏机不支持无间隙连续小票纸的承诺；纸型、黑标/间隙和驱动能力必须按精确型号/SKU确认。

### 4.3 手机平台直接打印

- 只有千牛和抖音/抖店确认可按平台 App 直接发起手机订单打印；抖音/抖店首次使用需先在电脑完成一次 PID 设置。
- 拼多多、1688、快手和风火递不得承诺从其手机 App 直接打印。
- 不支持直接打印的平台，先把标签或文件保存到手机，再在速印通中打开并打印。

## 5. 针式机纸张与速度边界

- 已确认通用纸宽 `100–241mm`，最大可打印内容宽度约 `203mm`，总厚度小于或等于 `0.45mm`；不支持小于 `100mm` 的窄纸承诺，也不支持厚证书、邀请函类硬厚介质。
- 可用普通纸、多联无碳复写纸及型号支持的链孔连续纸；不得使用热敏纸。
- 针式速度分为 `255 cps` 高速、`150 cps` 标准、`90 cps` 低速；TH850 为已确认的 `90 cps` 低速型号，TH650、TH650G、TH850GB、TH850GW、TM690、TG690、TD630、TD630G 属于已确认的 `255 cps` 高速组。其他型号/SKU不得靠型号名推断速度。
- 前进/后进、连续纸能力和用途必须按精确型号/SKU；不能因同系列或相似外观互相套用。

## 6. 默认包装与耗材

- 热敏机默认：`10` 张测试纸、`1` 根 USB-A 转 USB-D 数据线；默认随机 USB 数据线长度为 `1.2 米`。按型号确认内置/随附电源结构。测试纸仅供初次试打。
- 针式机默认：`2` 张测试纸、`1` 根 USB-A 转 USB-D 数据线、机器内已安装色带；默认 USB 数据线长度为 `1.2 米`，已确认配套电源线长度也为 `1.2 米`。已确认型号为内置电源并带连接电源线。正式多联纸和额外色带不属于默认承诺。
- 客户自购 `3 米` USB 线时，长度本身不是不兼容理由；只要打印机端接头匹配且线材支持数据传输就可以使用，纯充电线不适用。
- 考勤机默认：`1` 个电源适配器、`50` 张考勤卡、机器内预装 `1` 个通用考勤色带、`2` 颗挂墙螺丝；明确购买的加量套餐可以另加。
- 考勤机色带按通用考勤色带处理；优先使用原装考勤卡。第三方卡必须先核对规格，只有已确认的组 `15=00` 兼容处理可用，不得扩展成所有第三方卡都兼容。

## 7. 质保、维修与退换

### 7.1 质保

- 针式打印机默认整机 `3年`，包含打印头；历史天猫加普威 TH850 老款/纯 USB 路线例外为 `1年`。必须核对店铺、订单、型号和路线后再确认。
- 热敏机整机（打印头除外）按 `1年`，热敏打印头只按 `3个月`；不得加入里程限制。
- 针式机首年可按订单核实免费补发/更换前透明盖、托纸盘和 USB 数据线，运费由商家承担；这不缩短整机 3 年质保。
- 人为损坏、是否在保、是否免费及订单例外必须转人工核实，不披露内部特殊审批条件。

### 7.2 维修

- 有偿维修固定参考费：热敏机订单年龄不超过 1 年 `50元`，超过 1 年 `80元`；针式机 `150元`；考勤机 `80元`。已覆盖的质保维修仍免费。
- 费用为工厂固定价，不议价；最终受理前必须核对型号、购买时间、保修状态和故障分类。
- 维修寄送：客户承担寄往维修点的单程运费，商家承担维修处理及寄回运费；寄修地址必须从当前平台/人工实时取得，不保存静态地址。
- 远程安装和远程排障免费；客服时间为中国标准时间 `08:30–21:00`。
- 仓库签收机器后，正常情况下维修并寄回约 `3–5个工作日`；异常、缺件或老型号配件不足时转人工，不作绝对时效承诺。
- 完成一次有偿维修后，另有 `3个月` 维修服务质保；确认免维修工费，不等于重启或延长原厂质保。配件、运费、人为损坏和是否与原故障相关仍需人工确认。

### 7.3 退换与运费

- 非质量原因可按平台规则申请 `7天无理由`。
- 经核实的质量问题，可在 `30天` 内按平台规则办理退货退款或换货。
- 运费归属和平台保障是否适用由人工按订单、质量判定与平台规则核实；不在自动回复中指示客户选择运费险或退货保障。
- 不得主动建议客户退货、退款或换货；先排障。客户坚持、涉及质量判定、运费或金额时转人工，并按真实原因选择售后类型，不指导客户错误填写原因。

## 8. 绝对禁止

- 不把 `Needs confirmation`、`Unreviewed`、历史快照或内部 SKU 聚合当成当前对客事实。
- 不从型号相似、内部硬件、店铺标题或跨平台商品名推断功能。
- 不透露 TD630/TD630G 内部硬件关系；不把 TD630G 的电脑 Wi-Fi 操作发给 TD630 客户。
- 不把热敏打印头质保写成“3个月或30公里”；对客只保留 `3个月`。
- 不保存固定维修地址，不承诺实时价格、库存、在售、赠品或维修配件一定存在。
