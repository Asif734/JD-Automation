## 1. 速印通模板、文件与连接状态

- 本地用户模板只能保存在当前手机，不能导出、分享、随账号同步或转移到另一台手机。
- 客服后台制作的模板保留在线。只有客户以前申请过模板时，才可按对应订单编号搜索；未申请过模板就不能用订单编号找到。
- 手机重启、清理最近任务、关闭再打开蓝牙、打印机重启后，重新打开速印通通常会自动重新连接原设备。
- 只有卸载 App 或清除 App 数据后才需要重新选择设备。
- 蓝牙和 Wi-Fi 不会自动互相切换；确需更换连接方式或打印机时，使用“切换设备/连接另一台打印机”。已经连接成功时不要让客户无故切换。
- 已保存文件路径：针式打印机 → 文档打印 → 对应保存路径；已保存模板路径：针式打印机 → 模板。
- 速印通内不能取消已经卡在打印机队列里的任务；需在发送端或 Windows 打印队列中处理。

## 2. 售后、包装、驱动与发票

- 已批准的质量问题运费报销：使用经济型快递，不接受到付，不使用顺丰或其他高价快递；保存运费凭证，按批准上限报销，并转人工客服核实处理。
- 标准包装不附带驱动光盘或驱动 U 盘。驱动从官方网站下载，也可由客服通过邮箱或当前支持的联系方式发送。
- 外包装轻微破损不等于机器损坏。先检查机身、配件和电源线，再开机试打；有破损、缺件或功能异常时转人工办理换货或退货。
- 所有发票税率为 13%，不能调整。普通电子发票从订单页申请。增值税专用发票需客户为增值税一般纳税人，并收集公司名称、税号、开户银行、银行账号、公司地址和电话后转人工财务。
- 新手机出现“未注册的软件包”等提示时，文案会因系统而异；确认安装包来自官方渠道后，选择允许/授权继续安装。

## 3. 纸张、撕纸与套打位置

- 正确设置纸张规格并正确进纸是基础；软件页面尺寸、驱动纸张规格和固定页高也必须与实物一致。完成后打印机会自动把连续纸带到正确的撕纸位置，无需另设“自动撕纸模式”。如果只剩少量偏差，再在`Configure → tear-off position`中按2mm逐步微调。
- 实际撕纸时，让纸张出纸位置与最初进纸位置对齐，从透明前盖右侧提起纸张，沿锯齿边撕下。
- 清晰照片能确认是预印表格纸时，直接按预印表格套打处理；看不清时只确认一次是空白纸还是预印表格纸。预印表格只打印可变字段。
- 套打先匹配实物纸张规格与进纸方式，再调水平和垂直偏移。推荐页边距：左右 0.3、上下 0.5、页眉页脚为 0；客户要求居中时勾选水平居中和垂直居中。
- 预览出现大块空白通常是工作表被拆为两页：调整页边距，并选择“将整个工作表打印在一页”。
- 预览有内容但实物固定一侧缺失时，将前进纸导纸滑块移到最左侧再试；全部内容整体偏移时直接调整水平/垂直偏移。
- 正确页高、纸张规格与进纸设置保存后，必须完全关闭并重新打开打印软件，再取出纸张并正确重新插入后测试。
- D-label 主要用于热敏标签打印机，通常不用于针式打印机。

## 4. 进纸、打印头与空白打印

- 前进纸不吸纸时不需要按进纸键：先取出纸张和色带，清洁纸张感应器，完全干燥后重新装回测试；仍不能自动吸纸则转返厂检测。
- TG690 后进纸反复退出又吸入时，要清洁前后两个感应器，完全干燥后重新测试。
- 只走纸、空白或无击打声：先确认 USB/驱动，清空打印队列与 SPOOL/printers 隐藏任务，再打印 Windows 测试页。
- 打印头移动但没有击打声仍不打印，属于打印头故障，转人工维修。
- 自检或 Windows 测试页正常但文档空白时，可取下色带，清洁打印头周围机械区域后重装；不得套用热敏打印头清洁方法。
- 固定位置出现相同水平缺线/白带，通常是断针，转返厂维修。
- 乱码除驱动、USB、系统和隐藏任务外，还要排除不兼容云盒；不建议通过云盒解决针式打印乱码或空白。

## 5. 型号、网络、速度与供电

- TH880仅支持USB连接 Windows，不支持 Wi-Fi，也不支持原生 macOS；客服回复不得加入 Wi-Fi/IP 步骤。
- Wi-Fi 搜索应很快完成，不固定要求等待 3 分钟，也不把重启路由器作为常规步骤。先确认 2.4GHz 网络和准确密码。
- TD630G 多台 Windows 电脑使用：每台电脑都安装驱动，安装时选择 `Automatic → Search`，程序会自动识别并安装无线驱动/端口。手动 Standard TCP/IP 只作为搜索失败后由人工/技术使用的内部异常备选，不放入正常客户模板。
- 提速方法一：`打印首选项 → Layout → Advanced → Graphic → Print Quality`选择`DPI:180*144`；方法二：在`Configure`中取消勾选`One-way printing/单向打印`以启用双向打印。保存后完全关闭并重新打开打印软件，再取出纸张并正确重新装入后试打一份。机器没有单独的 High Speed/Draft 模式，不得编造。
- 技术寿命可写约 500 万字符；客户侧可参考约 1000–2000 张普通发票，实际取决于覆盖率、联数和浓度。
- 所有当前针式打印机支持的纸张总厚度上限统一为 0.45mm。
- 针式打印机不支持内置云打印、远程打印或云盒直接打印。Windows Wi-Fi 只限同一局域网；Mac 使用 USB。
- 车载/逆变器使用需要至少 200W 功率输出，并使用机器内置电源线连接稳定且符合额定输入的 AC 输出；不得改写成 300Wh，也不再推荐 800W。
- 自动关机功能不能关闭，并且只适用于蓝牙/Wi-Fi 型号。
- 特殊故障：按住电源键时灯亮、松开即灭，可先升级到确认的最新固件；仍不正常则转人工维修。普通不开机仍按“换插座→长按电源键→人工维修”的简短流程。

## 6. 业务软件边界

- 打送货单可使用管家婆或 Excel；快递面单可使用飞豆或快递助手；开具/打印发票使用税务局软件；其他表单使用与业务匹配的软件。
- 卖家不提供上述第三方业务软件。客户只问发票打印方法或视频时，不需要先追问打印机型号。
