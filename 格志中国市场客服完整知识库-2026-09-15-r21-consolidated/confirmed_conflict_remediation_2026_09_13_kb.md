# 2026-09-13 客服知识库冲突确认更正

## C01 — 打印从页面中间开始

先检查进纸方向、软件与驱动纸张规格、固定页高、页边距和实际装纸位置。如果这些项目都正确但起始位置仍然不对，关机后清洁对应进纸方向的纸张感应器，完全干燥后重新装纸测试。不删除前面的页面设置和装纸检查。

## C02 — 手机打印文字太粗

先在速印通 App 中降低对比度，再把纸厚扳手调高到最高第 6 档，或按实际打印效果选择所需档位，然后先试打一张。这样可避免文字过粗。客户使用手机 App 时，不对客宣称手机端具有 Windows 驱动专属的 Density、DPI、灰度阈值或图像增强控件。

## C03 — 客户愿补差价要求顺丰

天猫店铺常规使用中通，客服不承诺顺丰，也不承诺留言备注就一定可以安排。客户明确愿意承担差价时，转人工客服核实是否可以特殊付费安排顺丰；核实结果出来前不得做出承诺。

## C04 — 驱动安装提示缺少 .NET

普通情况下安装 .NET 4.8 后再运行驱动安装程序。Windows 7 可以选择安装 .NET 4.8，也可以跳过安装器、手动安装打印机驱动；手动安装驱动的路线不需要升级 .NET。

## C05 — Windows 打印机显示灰色或脱机

严格按物理连接在前的顺序处理：先重新插紧 USB 数据线或更换电脑 USB 接口，再在 Windows 中确认是否检测到常见的 `AT32` 设备，然后确认已安装驱动的端口与实际连接匹配。只有设备已经被检测到后，才继续检查脱机/暂停状态、队列、SPOOL 隐藏任务和重复驱动。设备恢复且端口匹配时，驱动通常会自动恢复在线。

## C06 — macOS 中 NOBLE PARAGON TD630 SZ 显示脱机

`NOBLE PARAGON TD630 SZ` 是 macOS 中已安装的打印队列/驱动名称，不是客户必须在 USB 设备中找到的物理设备名。显示 Offline/脱机时，先确认打印机已开机，再检查 USB 数据线和 Mac 端口连接。本次不编写未确认的 Mac 安装教程或其他系统功能，待用户后续补充。

## C07 — 表格段落断开或异常空白带

当图像表现为纵向走纸不连续、表格上下段分离或异常空白带时，先在 `Configure` 中启用 `One-way printing/单向打印`后试打。问题仍在时转人工维修。只有明显的水平打印头运动失步、逐行阶梯状左右错位才直接进入失步维修分支。

## C08 — 打印乱码的证据分流

乱码必须根据客户证据选择一个对应分支：有残留任务时清除队列和 SPOOL 隐藏任务；Windows 连接不稳定时检查 USB 数据线、接口和匹配端口；不兼容的第三方手机 App 直接打印时，先导出/保存文件，再用速印通打开打印；Mac 时检查是否使用了不支持的系统或错误的 Mac 驱动。没有对应证据时不同时堆叠全部步骤。

## C09 — 水平拖墨或划痕

先关机断电，取下色带，清理打印头和支架周围的纸屑或其他异物。然后不安装色带使用多联纸测试，观察第二联。如果仍然出现明显划痕，按打印针无法回缩处理，转人工安排打印头维修或更换。已经确定为固定、连续、贯穿页面的硬件黑线可保留直接维修分支。

## C10 — 多联纸卷曲、折叠或分层

多联复写纸正常应连接成一整套。各联分层、错位、卷曲或折叠会导致走歪或卡纸。先更换完整纸套，或把整套纸对齐并正确放置，再判断打印机；不得先定性为打印机故障。

## C11 — 新机外壳没有明显 Logo 或型号

部分新外壳不一定在正面显示醒目的厂商 Logo，当前产品也可能按打印宽度分类，但准确型号仍以机身或标签/铭牌信息为准。不得编造具体型号，也不能因正面没有 Logo 就说产品不是正品。只有型号会改变后续操作时才请客户拍摄标签/铭牌。

## C12 — 打印机会关机且不进纸

将关机和不进纸拆分处理。关机分支：换一个已知正常的墙插电源座测试，仍会关机则转人工维修。不进纸分支：从前方正确插入纸张；仍不自动吸入时，关机后清洁对应的前进纸纸张感应器。这个组合症状不需要拔 USB，也不需要按进纸键。

## C13 — 不固定位置的断字或缺笔画

对一般的、不固定在同一位置的断字/缺笔画，先检查色带和打印头：确认色带是否安装正确、是否扭曲、破损或过旧，并用无色带的多联纸测试检查打印头。硬件检查后再改用常见字体，然后将纸厚档位向低调一档并试打。

## C14 — 单个字体孤立缺笔画

这是 C13 的更具体证据分支。如果只有个别字的笔画缺失，同一页的表格线和其他字体都正常，先按字体/字形兼容问题处理，更换常见字体对比。只有更换不同字体后同一固定位置仍重复缺线，才进入色带/打印头硬件诊断。

## C15 — 打印机无法关机

先取出纸张，按住电源键，看到红灯闪烁时松开。如果打印机仍未关机，断开打印机的电源供应。

## C16 — Windows Wi-Fi 驱动和端口

正常对客流程必须使用 `Automatic → Search`，选中检测到的打印机后继续，安装程序会自动安装无线驱动和端口。手动 `Standard TCP/IP` 仅作为 Automatic 搜索失败后的内部异常排查备选，由人工/技术按自检页 IP 和实际网络核对；不出现在正常客户回复模板中。

## C17 — ZIP 驱动包无法解压

官方下载可能提供 ZIP 压缩包或 EXE 安装程序。只有 ZIP 压缩包需要解压；EXE 文件直接运行，不需要先解压。ZIP 无法解压时，回到下载页选择 EXE 版本并直接运行。

## C18 — Windows 测试页文字重叠

先重新定位纸张起始边并再打一次，或不使用该 Windows 测试页判断，改打一份实际文档。只有实际文档也发生重叠时，才继续检查软件/驱动纸张规格和驱动是否安装正确。不仅根据一张测试页直接判定打印头失步。

## C19 — Configure 按钮的含义

本条为内部界面语义：点击 `Configure` 会打开独立的驱动设置窗口；附近的日期/构建号不是打印机型号，也不是一项功能。日常指导客户进入 Configure 时不需要主动说明本条；只在客户明确询问按钮或旁边日期的含义时回答。

## C20 — 客户自购 3 米 USB 数据线

默认随机 USB 数据线长度为 1.2 米；已确认配套电源线的默认长度也为 1.2 米。客户自购 3 米 USB 线时，长度本身不是不兼容理由；只要打印机端接头匹配，并且该线支持数据传输，就可以使用。纯充电线不适用。

## U01 — 纸张正常走动但打印头停在中间

当现场视频或客户描述已经确认纸张正常走动、但打印头停在中间不左右移动时，优先按打印头/字车机械路径处理，不先归因于驱动、端口或连接。先关机断电，取下色带，清理打印头下方、周围和导轨上的可见纸屑或异物；再重新开机，只从外部观察打印头是否完成一次正常的左右移动，不得在通电状态触摸或强推运动部件。清理后仍不移动时，按字车电机或打印头机械故障转人工维修。只有打印任务没有到达打印机、机器没有出现走纸动作时，才进入驱动、端口和连接排查。USB 单一连接版本没有本机自检功能，不要求执行不存在的自检。

## U02 — TD630 前进纸、后进纸和连续纸能力

用户于 2026-09-13 最终确认：TD630 支持前进纸和后进纸。由于本知识库中的后进纸指后部拖纸器/链轮连续纸路径，TD630 同时纳入后进连续纸教程和固定页高流程。TD630 与 TD630G 均可按客户实际使用的前进单张纸或后进连续纸发送对应教程；连续纸左右两侧各三个孔必须对称套入拖纸器并保持拉直。不得再使用“TD630 仅支持前部单张进纸”“TD630 不支持后进纸”或“不得向 TD630 发送后进连续纸教程”的旧口径。
