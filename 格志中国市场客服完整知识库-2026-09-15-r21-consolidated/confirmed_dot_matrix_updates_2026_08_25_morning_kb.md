# 针式打印机已确认更正（2026-08-25 上午）

来源：`Corrected aug 25, Test QnA Verification-2026-08-25-Morning-D.xlsx` 中的 28 条问题、已确认正确答案及复核备注。

## 1. 低温运输和结露

- 机器从室外低温环境搬到室内后不要马上通电。
- 保持包装完整，在常温下静置数小时；确认没有结露、水汽或霜后再开机。
- 已受潮时必须完全干燥；开机后出现异味、异响或指示灯异常时立即停止使用并转人工售后。

## 2. 送货清单和模板制作

- 根据客户图片制作 Excel 模板时，字段、明细行、签字区、合并单元格、行高、列宽和字体大小都要尽量准确匹配。
- 部分行字体变小时，统一字号并关闭“缩小字体填充/自动适应”；必要时增加行高或列宽。
- 表格竖线压住下方说明文字时，在原始模板中取消多余竖向边框，必要时合并说明行单元格。
- 打印前确认预览只有一页；删除空白页或设置正确打印区域。

## 3. 连续纸后进纸

- 仅对支持后进纸和连续纸的型号提供本步骤；不支持后进纸的型号继续按原型号规则处理。
- 将纸张左右两侧各三个孔正确套在两侧拖纸器/进纸夹上，关闭压盖并锁紧。
- 保持纸张拉直、左右松紧一致，然后按中间的“走纸/进纸”键，机器会自动吸入纸张。
- 连续打印前设置与实际撕线间距一致的固定页面高度，并连续测试两页。

## 4. 提高打印速度

- 提速的原理是降低打印质量或分辨率/DPI，并可启用双向打印；具体只使用下列已确认控件。
- 在`打印首选项 → Layout → Advanced → Graphic → Print Quality`选择`DPI:180*144`；低DPI会降低打印质量。
- 在`Configure`中取消勾选`One-way printing/单向打印`以启用双向打印。
- 保存后完全关闭并重新打开打印软件，再取出纸张并正确重新装入后试打一份。
- 双向打印用于提速，不等于双面打印。

## 5. 图片、底色、网点和粗线

- 模板或图片中出现整行实黑时，先删除单元格或图片背景色。
- 打印出现大量网点时，降低对比度和灰度阈值；优先使用原始 PDF/Excel，不使用压缩聊天截图。
- 表格线太粗时可把模板边框改细，同时降低 Density/灰度阈值并把纸厚扳手调高。
- 只有所有内容都过黑时才整体降低浓度，调整后先试打一张。

## 6. 红灯后自动关机和电源结构

- 本次复核涉及的针式打印机使用机器内置电源线，没有外接电源适配器，不要要求客户检查或更换不存在的适配器。
- 亮红灯后自动关机时停止反复开机，等待至少 15 分钟冷却；检查卡纸、色带缠绕和纸路堵塞，并改用稳定墙插。
- 冷却后仍亮红灯或自动关机时停止使用并转人工检测。
- 明确是“打印过程中突然关机”时，对支持本机自检的型号先打印自检页检查固件版本；版本较旧时按技术资料升级，升级后仍关机则返厂维修。USB 单一连接且不支持自检的型号不要求执行自检。

## 7. 无原包装退货

- 客户没有原包装时，应使用足够结实的替代包装和缓冲材料，确保机器在箱内不会晃动。
- 无需特别要求固定打印头，也无需重复说明显而易见的拔线步骤。
- 包装费用不由店铺承担；只有客户询问费用时再明确说明，并以平台售后规则为准。

## 8. 乱码、重叠和多余字符

- 主要先检查隐藏打印任务和 USB 连接松动。
- Windows：右击开始键 → 运行 → 输入 `SPOOL` → 打开 `printers` → 删除隐藏任务，同时清空打印队列。
- 重新插紧 USB 数据线，必要时换 USB 接口或数据线。
- 不兼容的操作系统也可能产生乱码；Mac 使用错误驱动时应安装对应 Mac 驱动。

## 9. 上下颠倒、重复和重叠

- 取消双面打印、手动双面、镜像打印和反向打印；页面旋转设为 0°。
- 清空队列，重新打开文件，确认预览只有一页且方向正确。
- 可以保留用于提速的“双向打印”。

## 10. 拖黑、局部缺字和色带

- 黑色拖痕或局部缺字先检查色带是否扭曲、松弛、跑出导片或缠在打印头附近。
- 安装色带时必须保持平直、不能扭转。色带撕裂、起白点或扭转时，先取下色带，不装色带用多联纸打印并查看第二联；第二联文字中没有水平横线，说明打印头正常，更换新款针式打印机通用色带即可；考勤机和未确认老款不套用。
- 调高纸厚扳手并重新测试；局部文字异常时也可更换适合针式打印的字体进行对比。
- 走纸组件被取出后出现拖黑，先按上述色带平直和纸厚扳手步骤处理；组件无法正确复位时转人工售后。

## 11. 固定白线和固定缺印

- 图片看起来像“重影”但实际呈现稳定、同位置白线时，不按双向打印处理。
- 取下色带，不安装色带，用多联纸打印并查看第二联；第二联相同位置仍缺线即可确认打印头问题。

## 12. 页面跨页和右侧大面积空白

- 打印预览必须只显示一页；有空白页时删除空白页或设置正确打印区域。
- 页面高度与实际撕线间距一致，方向与实际单据一致，并使用保持纵横比/适合页面。
- 修改设置后退出旧纸并重新进纸，再做小幅偏移调整。

## 13. 一直出空白纸

- 先清理打印队列和 `SPOOL/printers` 隐藏任务。
- 检查文档是否包含额外空白页，并检查打印区域。
- 检查 USB 数据线是否松动、端口是否正确，同时确认色带安装到位。
- USB 单一连接版本的针式打印机没有本机自检功能，不要把自检作为必做步骤。

## 14. 前后进纸感应器和大量吐纸

- 前进纸时一次吸入半张或更多纸，或打印一张后又多走出大量纸，优先判断前进纸感应器异常。
- 后进纸出现同类现象时检查后进纸感应器。
- 取出纸张并关闭打印机，用湿纸巾或酒精轻轻清洁对应传感器；酒精完全挥发后重新装纸测试。
- 通常按实际进纸方向清洁对应感应器；TG690 后进纸反复退出又吸入是已确认例外，需要清洁前后两个感应器。

## 15. 固定位置重复圆圈或“8”字符

- 同一位置连续打印圆圈或“8”字符时，优先判断打印头卡住、无法横向移动。
- 关机取下色带，检查打印头下方和导轨是否有异物；再开机只观察打印头能否自动左右移动一次。
- 仍不能移动时转人工维修。
- USB 单一连接版本没有本机自检功能，不要求客户执行不存在的自检。

## 16. 已确认保持不变

- 预印表格只打印可变数据，避免重复打印原有表格线。
- 严重浅印、零散针点和不完整线条先用原始 PDF/Excel、文档/黑白模式，并检查色带、纸厚和测试页。
- 位置跨页时检查固定页面高度、分页、页边距和打印预览。
- 打印头完全无电源反应时使用顶部电源按钮、墙面插座并转人工售后；不添加不存在的 I/O 主开关。
