# 针式打印机已确认更正（2026-08-24）

## 1. 连续纸、固定页高和打印位置

- Windows 精确路径：`控制面板 → 硬件和声音 → 设备和打印机 → 右击对应打印机 → 打印首选项/Printing Preferences → Layout → 高级/Advanced → 纸张/输出 → 纸张规格`，选择匹配的纸型后点击确定；再进入 `Configure`，按实际撕线间距/孔数选择固定页面高度。后进连续纸时勾选`固定页面高度`，并取消勾选`删除页面底部空白`、`删除左边空白页`、`删除页面顶部空白`、`将位图图像输出到计算机`和`纸边孔长计算`；`单向打印`保持原设置。点击`导入/Import`后再点击`确定/OK`。
- 修改固定页高、孔数或纸张规格并保存后，必须完成两项操作：先完全关闭并重新打开当前打印软件；再从打印机中取出纸张并按新设置正确重新装入，然后测试。
- 连续纸页高使用“等分”而不是“联数”表述：三等分 `93.1 mm（holes 22/3）`，另有 `101.6 mm（holes 8）`、`127 mm（holes 10）`，二等分 `139.7 mm（holes 11）`，整张 `279.4 mm（holes 22）`。“二联/三联/六联”只用于表述无碳复写纸的层数。
- 孔距口径：孔中心排列如 `O--O--O`，第一孔中心到第三孔中心约为 `1 inch`；因此相邻两孔中心距约为 `0.5 inch`。禁止写成“相邻孔距约 1 inch”。
- 纸宽可到 `241 mm`，但最大可打印宽度约为 `203 mm`；普通送货单、发票在可打印区域内可以使用。
- App 中勾选“保持纵横比”后，选择纸张尺寸会自动调整高度和宽度，无需关闭“默认纸张”。
- 手机端点击打印预览无反应时，先按实际纸长/孔数选纸；需要时可选默认纸张，但选完后必须返回并重新选择文档，然后再预览。
- 连续打印逐张偏移时，先数孔判断整张或二等分，再选对应已有纸型，不先要求测量或创建自定义纸型。
- 打印倾斜通常不会在打印预览中显示；先检查纸张是否平直、两侧链轮孔是否对齐、链轮夹是否锁紧以及进纸是否偏斜。

## 2. Windows 驱动、设备名称和软件打印

- Windows USB 驱动直链：`https://zjweiting.com/nobel/apk/DotNobleDriver.exe`。USB 普通驱动安装不需要先升级固件。
- 设备管理器中的正常通用硬件名称可能显示为 `AT32 Printer FSS mode`；TD630/TD630G 也可能显示为 `USB Composite Device`。硬件设备名称不必与机器型号一致，通常只有安装后的打印机驱动名称显示具体型号。
- Windows显示“未知USB设备/设备描述符请求失败”不属于正常AT32名称，表示USB识别或连接不稳定；先更换电脑USB接口，再更换USB数据线测试。
- 无法打印时，先把 USB 数据线换到电脑的另一个 USB 口，再检查驱动和队列。不得仅凭 `AT32 Printer FSS mode` 判断为固件/升级故障。
- 安装驱动后，从电脑打印一般不受业务软件品牌限制，只要该软件能调用 Windows 已安装的打印机即可；在软件中选中本机驱动或把它设为默认打印机。管家婆、Excel、飞豆/快递助手、税务开票软件都可按此原则处理。我们不提供或维护这些第三方业务软件。
- 如果误选 `Microsoft Print to PDF`、`WPS PDF` 等虚拟打印机导致弹出保存窗口，改选实体针式打印机驱动，并建议把实体驱动设为 Windows 默认打印机。

## 3. 中国市场速印通 App

- 中国市场客户统一称 `速印通`，不要把 `Grozziie` 作为对客 App 名称。
- iPhone 和鸿蒙：在 App Store/应用市场搜索 `速印通`，认准 `G` 图标。
- Android：扫描机器上的 `G` 二维码，或发送官方链接 `https://www.zjweiting.com/files_dot/Grozziie.apk`。
- 商店搜索页一直加载通常是网络问题，不代表 App 已下架；先换 Wi-Fi/手机流量再搜，仍不可用时发送官方 Android 链接。
- TD630 和 TD630G 的 App 操作方法相同，iPhone、Android、鸿蒙也按同一套连接流程；上下文已经确认是支持手机的型号时，直接发送手机 App 连接教程，不重复追问型号。
- 手机连接默认优先使用蓝牙；只有客户明确要求 Wi-Fi 时才优先发 Wi-Fi 流程。iPhone 也可通过速印通使用蓝牙打印，与 Android 的 App 连接和使用流程相似。
- App 账号可用邮箱注册；没有邮箱时可用 `手机号@163.com` 或 `手机号@139.com` 形式。密码为 8–20 位，并且至少包含数字、小写字母、大写字母和 `@#%$` 中的一个符号，例如 `@Ab12345`。不想注册时可使用游客登录。
- 两台手机都可以安装并使用 App，不需要手动让另一台手机断开打印机。iPhone/鸿蒙从应用商店下载，Android 从官网下载安装。客户编辑后可把模板保存在 App 本地并重复使用；本地模板不随账号同步，也不能转移或导入新手机，换手机后需要重新创建。客服后台制作的模板可以搜索。

## 4. 模板、图片与打印质量

- 通常可免费制作 2 个模板。无需索要购买证明、聊天截图、软件名称或订单号；只问客户使用电脑还是 App。
- 电脑模板：根据客户纸张照片制作 Excel，尽量匹配行高、列宽和合并单元格。App 模板：按 App 模板创建流程制作。
- 客户要求移动、对齐字段或仿照照片制作版式时，识别为模板制作需求，直接说明可以协助制作并收集纸张照片、尺寸和电脑/App 使用方式。
- iPhone 等手机需要输入数值后打印单据时，使用速印通内置模板；客服可协助制作，客户再编辑数据并打印。
- App 打印过深、拖印或字太粗时，先降低对比度，再把纸厚扳手调到最高第 6 档或按实际打印效果选择档位，试打一张。App 中没有“图像增强”选项，也不提供 Windows 驱动的 Density、DPI 或灰度阈值。
- 一般、不固定位置的缺笔画或断字：先检查色带和打印头，确认色带安装、保护膜、扭曲/破损/老化情况，并取下色带用多联纸测试打印头；然后再改用常见字体，并将纸厚档位向低调一档试打。
- 特定字体只有个别字缺笔画，但表格线和其他字体正常时，先按字体/字形兼容处理并改用常见字体对比；更换字体后同一固定位置仍缺线，才进入色带/打印头硬件诊断。图片清晰显示多条竖向笔画在同一高度有一致水平白线时，可直接判定打印头针断裂/缺针并申请维修。
- 不建议用针式打印机打印截图、照片和彩色文档；图像可能大面积打印成实黑，造成打印头过热，严重时可能烧坏或损伤打印头。

## 5. 噪音、打印头和售后排查

- 正常打印但声音较大：对客解释针式机通过打印针击打成像，本机支持最高六联纸，为确保末联清晰需要较强击打力度，所以声音比热敏机大。机器没有静音/低噪模式，不虚构相关设置，也不建议防震垫解决正常工作声。
- 打印头卡在中间并持续异响：关机，取下色带，清理打印头周围和导轨，再在上盖打开、人员不触碰运动部件的情况下开机观察。正常开机时打印头会自动左右移动一次；仍卡住或持续异响时转售后。若同时出现后进纸不送纸和缺纸红灯亮，清理后进纸感应器并测试前进纸，仍无效转人工维修。
