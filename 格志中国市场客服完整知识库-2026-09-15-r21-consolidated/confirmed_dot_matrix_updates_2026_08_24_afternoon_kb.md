# 针式打印机已确认更正（2026-08-24 下午）

## 1. Windows 驱动与软件

- 驱动安装入口按客户目的分流：支持手机/WiFi 的针式打印机需要配置 WiFi 时选择 `Automatic → 下一步`；需要安装 USB 驱动时选择 `USB → 搜索 → 选中搜索到的设备 → 下一步`。仅支持 USB 的机型选择 Auto 或 USB 都会安装 USB 驱动。安装后打印测试页。“不猜型号”属于内部边界，不需要主动对客说。
- Windows 驱动安装后，只要业务软件能调用 Windows 已安装的打印机，通常即可打印；Excel、管家婆、飞豆/快递助手、税务开票等不受打印机品牌限制。客服可远程协助安装驱动和调试打印，但不提供或维护第三方业务软件。
- 电脑中有多个队列时，先使用当前可用的在线驱动，并清空任务、核对连接和端口。只有上述检查后仍确认存在持续的重复或错误驱动故障，才删除错误项并使用官方安装包重装；不得仅因另一个匹配队列离线就全部删除。
- 当前打印机驱动安装包不按 USB、Wi-Fi 或蓝牙连接方式区分下载，同一安装包也用于热敏打印机；但安装包通用不代表设置或功能通用。针式打印机安装时可能出现AK890/TG890、AK890/TD630等通用驱动对应关系，仍必须选择实际检测到且兼容的打印机/连接路径并打印测试页；针式驱动设置不得套用到热敏机、标签机或考勤机。

## 2. 进纸、纸张和打印位置

- 前进纸不自动吸入时不需要按进纸键，也不强推纸张。先取出纸张和色带，关机后用少量酒精清洁纸张感应器，完全干燥后重新安装测试；仍不能自动吸入则转返厂检测。TG690 后进纸反复退出又吸入时，清洁前后两个感应器。
- 图像显示纸张宽度明显过窄且前进纸倾斜时，建议使用 `100–241 mm` 宽的纸张，放平并让导纸器贴合纸边；过窄的纸容易走斜。
- 打印内容压到左侧链轮孔时，先在 `打印首选项 → Configure` 中取消 `删除左边空白/Remove Left Blank`，再检查导纸位置和文档左边距。
- 驱动中常用固定页面高度：标准三等分 `93.1 mm（holes 22/3）`，另有 `101.6 mm（holes 8）`和 `127 mm（holes 10）`，标准二等分 `139.7 mm（holes 11）`，整张 `279.4 mm（holes 22）`。标准纸可直接按实际撕线间距/驱动选项设置，只有非标准纸才需要实测。
- 预印表格出现双重线或双重文字时，先检查同一张纸是否重复打印。在预印单据上只打可变数据，不要再打一次整个表格和固定文字；需打完整表格时改用空白纸。
- 根据型号和客户实际场景指导前进纸或后进纸，只回答客户当前的进纸问题，不主动增加无关解释。
- 单张/多联单据每次放入一整套多联纸；只有支持后进纸的型号才能使用链轮连续进纸。

## 3. 连接、速印通 App 和模板

- 速印通搜索设备前，确认打印机已开机并已正确放纸。
- App 出现“未找到设备/No Device Found”时，先确认开机、放纸和权限，点击 `刷新/Refresh`；仍无设备时，点击右上角打印机图标重新连接。App 正常流程不使用 `Enter IP`；IP 端口仅用于 Windows 网络打印排查。
- 速印通 App 可在模板功能中创建、编辑并打印库存管理等单据，不仅限于导入现有文件。
- 多台手机或电脑可以配置使用同一台打印机，但打印任务必须按队列顺序执行，同一时间只处理一个任务。
- 客户只问教程视频或机型推荐时，不主动提微信打印。客户明确要求通过微信或电话指导时，优先在当前平台聊天中发简单步骤、图片或已审核视频；客户坚持电话指导时转人工客服。

## 4. 二维码识别与 App 名称

- 需要手机连接时，请客户在 `速印通App内` 扫描机身上标有 `APP连接二维码` 的码，不要使用手机系统相机扫描。
- 驱动/教程二维码指向 `https://www.zjweiting.com/download.htm`；客服二维码用于联系客服；只有支持手机连接的型号才使用 App 连接二维码。
- 中国市场对客 App 名称统一为 `速印通`；`Grozziie` 只可作为安装包文件名或来源资料标识，不得作为中国市场客户的 App 名称。

## 5. 打印质量

- 整页过黑、图片大面积实黑时，在速印通中降低对比度，在 Windows 驱动 `Configure` 中降低 `Density/阈值`；数值越高通常打印越深。调整后先用普通文字文档测试；仍异常或打印头已损伤时转人工检测。
- `Density/阈值` 在 Windows 驱动的 `打印首选项 → Configure` 中调整；`DPI/打印质量` 也会影响深浅、清晰度和速度。

## 6. 包装、纸张与耗材

- 标准包装内含两张测试纸；正式使用的打印纸需另行购买。
- 支持纸宽 `100–241 mm`，纸张总厚度不超过 `0.45 mm`，长度不限；支持 `1–6 联`（原件 + 最多 5 张复写）。该范围覆盖市面上 95% 以上的常见打印纸。
- 所有新款针式打印机范围内的色带通用，无需按具体新款针式机型号区分；考勤机、热敏产品和未确认的老旧型号仍按各自耗材规则处理。

## 7. 发货、发票和退货

- 天猫店铺常规使用中通快递，不承诺顺丰或次日必达。客户明确愿意承担顺丰差价时，转人工核实是否可以特殊付费安排，核实前不得承诺，也不承诺留言就一定可以。仓库或订单页已显示其他安排时，以实际订单为准。已批准质量问题运费报销时应使用经济型快递，不到付、不发顺丰或其他高价快递，保存凭证并按批准上限转人工核实。
- 本店不提供手写收据。所有发票税率统一为13%，不能调整；普通电子发票从订单页申请。增值税专票需客户为一般纳税人，并收集公司名称、税号、开户银行、银行账号、公司地址和电话后转人工财务。
- 天猫订单按平台规则支持 7 天无理由退货；非质量问题退货的寄回运费由买家承担，最终以订单售后页和平台规则为准。

## 8. 户外电源

- 本次复核涉及的针式打印机使用机器内置电源线，没有外接电源适配器；不得要求客户核对或更换不存在的适配器。
- 车载/逆变器使用需要至少 `200 W` 功率输出，并提供稳定、与机器额定输入兼容的 AC 输出；机器内置电源线直接连接逆变器 AC 插座。
