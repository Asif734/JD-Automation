# 针式打印机连接方式与系统支持

## 正式型号映射

| 型号 | USB | 蓝牙 | Wi-Fi | Windows | 原生 macOS |
|---|---|---|---|---|---|
| TD630 | 支持 | 支持 | 不支持 | 支持 | 支持 |
| TD630G | 支持 | 支持 | 支持 | 支持 | 支持 |
| AK910 | 支持 | 不支持 | 不支持 | 支持 | 不支持 |
| AK915 | 支持 | 不支持 | 不支持 | 支持 | 不支持 |
| AK890 | 支持 | 不支持 | 不支持 | 支持 | 不支持 |
| TG890 | 支持 | 不支持 | 不支持 | 支持 | 不支持 |

## 客服规则

- 只有 TD630、TD630G 支持 Windows 和原生 macOS。
- 其他针式打印机电脑端仅支持 Windows；不得发送 macOS 驱动或承诺原生 Mac 可用。
- TD630 支持 USB 和蓝牙，不支持 Wi-Fi。
- TD630G 支持 USB、蓝牙和 Wi-Fi。
- AK910、AK915、AK890、TG890 均按 USB + Windows 回答。
- 型号不明确时，先请客户提供机器铭牌和电脑系统。
