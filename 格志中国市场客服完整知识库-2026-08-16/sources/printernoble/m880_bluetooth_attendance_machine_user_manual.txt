This menu allow to configure the time, date, and date format. After entering the date and

7.2. Set Working Time
In this menu, you can select the Shift and set the Working Time for each shift.
In the Shift Selection drop-down menu, you will see four options:  
Flexible Work Schedule – for manual punch
1, 2, 3 – for different shift times.
Flexible Work Schedule:
The Flexible Work Schedule mode allows employees to punch in and out without fixed start 
and end  times. This mode is designed for variable or non-standard hours. The attendance 
record is printed on  the punch card column according to the cursor’s position.
14

--- page 17 ---
Manual Punching – Employees can clock in and clock out at any time by pressing the 
appropriate  buttons (1 – 6) by changing the cursor’s position.  
No Fixed Shift Time – The device does not compare punch times to a predefined schedule, 
so no  late or early status is recorded automatically.  
Color Printing – When using Flexible Work Schedule, you can manually choose the print 
color  (Black or Red). The Auto color feature is disabled because no fixed shift times exist 
for  comparison.  
Best Use Cases – Ideal for part-time workers, freelance schedules, or workplaces where 
daily  start/end times change frequently.
Shifts 1, 2, and 3:
The P unch C ard Attendance M achine supports up to three fixed shifts. Selecting Shift 1,  2,  or 3  
allows  you to define and manage separate working times for employees.
Shift 1 – Select this to set the Clock-In and Clock-Out times for one shift. This is typically 
used  for single-shift operations.
Shift 2 – Select this to set the Clock-In and Clock-Out times for two shifts. This is useful for  
organizations with a day and evening shift.  
Shift 3 – Select this to set the Clock-In and Clock-Out times for three shifts. This is ideal for 
24 hour operations with rotating or round-the-clock staff.
How It Works:
Each shift has its own Clock In and Clock Out times that you can configure in the menu.
The device compares punch times to the scheduled shift time to determine late arrivals or 
early  departures.  
When using Auto Color Format, the machine automatically prints Red if an employee 
punches in  late or leaves early according to the set shift time. 
This mode ensures accurate attendance tracking for multiple shifts in a structured work 
schedule.
Note: On every screen in the app, you will see detailed instructions to help you complete the 
setup.

In this menu, you can set the Punch Card Print Format.
Day Format – The default preset is 90 Degrees, so the device prints the date at 90 Degrees 
by  default. If you want to change this setting, you can select the date print angle: Normal.
N ormal 90  D egree
Time Format – Choose between 24-hour or 12-hour time display.  
UTC Format – Select either Normal or USA format. 
Color Format – Choose the punch card printing color: Auto, Black, or Red.
How It Works:
Auto – The device automatically prints Red if an employee punches in late or leaves early  
based on the scheduled shift time. To use this feature, you must select Shift 1, 2, or 3.  
Black or Red – The device always prints in the selected color regardless of punch timing.

7.11. Music Time Settings
In this menu, you can define and set music play times for every shift's in-time and out-time.
Two parameters must be set for each shift: Play Music After and Play Music For. 
Play Music After specifies the delay (in minutes) after the in-time or out-time before 
the music starts. 
Play Music For determines the duration (in seconds) the music will play
Example: If Play Music After is set to 1 minute and Play Music For is 10 seconds, music will 
play at 8:01 if the shift time is 8:00. After entering the values, tap the "Set" button to apply 
the configuration.
Note: On every screen in the app, you will see detailed instructions to help you complete the 
setup.
7.12. DST
With this menu, you can set Daylight Saving Time (DST) changes to Automatic or Manual.
Auto DST – The machine will automatically adjust for DST according to the scheduled 
changes. 
Manual – The machine will not adjust for DST unless you change it manually.
