# 考勤机班次交集计算知识库

## 0. 第一原则：先识别员工组，再合并设备班次

处理客户班次时，必须先分清“有几组员工”，再计算机器需要设置几个班次。客户说出的每一个时间段不一定代表一组新员工；同一组员工一天可能有两段工作时间和四次打卡。

固定顺序：

```text
识别员工组
→ 整理每组员工的全部上班、下班和中途打卡时间
→ 判断不同员工组的时间是否存在共同区间
→ 用交集尽量合并为可共用的设备班次
→ 检查最终设备班次数是否不超过3组
→ 保留各员工组原始排班用于迟到、早退核算
```

基本要求：

- 先问清每段时间分别属于哪一组员工。
- 同一组员工的多个工作时段要放在同一员工组下分析，不能误数成多组员工。
- 不同员工组只要存在有效共同区间，应优先评估能否共用同一个设备班次和同一对上班/下班栏位。
- 合并仍按交集公式计算，不相加、不取平均。
- 没有共同区间的时间保留为独立设备班次。
- 合并目标是让不同员工组尽量共用设备的最多3组班次，不是修改员工真实排班。

### 0.1 员工组辅助判断

- 判断员工组时，首先以每组员工正常一天累计实际工作约 `8小时`为主要依据；在多个可能分组方案中，优先检查能否形成约8小时的合理员工组。
- `10–12小时`只能作为明确存在加班时的次级判断，不能与8小时规则同等优先，也不能只凭较长总工时直接认定为同一组员工。
- 累计工作时间按每段“下班−上班”分别计算后相加，不把休息间隔计入工作时长。
- 例如 `08:00–12:00`、`13:30–18:00`、`18:30–21:30`累计工作 `4+4.5+3=11.5小时`；仅凭时长不能优先认定为一组员工。客户确认属于同一组且最后一段为加班后，才按一组员工的第一、第二、第三班次栏位设置。
- 工作时长只能作为辅助判断；若客户表述仍可能对应不同员工组，继续遵守统一确认原则，只问一次“这些时间属于同一组还是不同组员工”。

## 1. 统一原则

- 班次重叠时，先把时间换算为从当天 `00:00` 起算的分钟数。
- 求共同区间时使用交集，不得把两个班次的时间直接相加，也不得用平均时间代替交集。
- 计算公式：

```text
重叠开始 = max（各班次上班时间）
重叠结束 = min（各班次下班时间）
```

- 如果 `重叠开始 < 重叠结束`，存在共同时间：

```text
共同班次 = 重叠开始–重叠结束
重叠时长 = 重叠结束 − 重叠开始
```

- 如果 `重叠开始 ≥ 重叠结束`，没有共同时间，应保留为独立班次，不能合并。

## 2. 普通重叠示例

```text
A班：08:00–17:00
B班：09:00–18:00

重叠开始 = 09:00
重叠结束 = 17:00
共同班次 = 09:00–17:00
重叠时长 = 8小时
```

```text
A班：08:00–12:00
B班：11:00–16:00
共同班次 = 11:00–12:00
```

## 3. 完全不重叠示例

```text
A班：08:00–12:00
B班：13:00–17:00
```

因为 `13:00 ≥ 12:00`，没有共同时间，应设置为两个独立班次，不能合并。

## 4. 跨夜重叠

跨夜班次应先把次日时间加 `24小时`，放到同一条连续时间轴计算：

```text
A班：20:00–02:00 → 20:00–26:00
B班：22:00–03:00 → 22:00–27:00

共同时间：22:00–26:00
对客显示：22:00–02:00（次日）
```

## 5. 三个及以上班次共同重叠

```text
A班：08:00–17:00
B班：09:00–18:00
C班：10:00–16:00

共同上班时间 = max(08:00, 09:00, 10:00) = 10:00
共同下班时间 = min(17:00, 18:00, 16:00) = 16:00
共同班次 = 10:00–16:00
```

## 6. 使用边界

- 共同时间只用于网页中的 `Common Shift Times` 计算或班次压缩建议。
- 在考勤机自动定位场景中，共同区间还可作为同一栏位的分界：对于被归入该共同班次的员工，最晚上班时间及以前的上班打卡进入该班次的上班栏，最早下班时间及以后的下班打卡进入该班次的下班栏。
- 共同时间不能替代员工所属的原始班次。
- 判断迟到、早退时，必须按照员工所属原始班次与实际打卡时间计算。
- 不得统一按共同区间判断迟到、早退，否则会产生误判。
- 共同区间不是“两个班次的平均值”，也不代表原班次边界已经被无损合并。

### 6.1 已确认案例：A、B、C共用第一班次栏位

```text
A：08:00–17:00
B：15:00–00:00（次日，计算时为24:00）
C：13:00–19:00

共同开始 = max(08:00, 15:00, 13:00) = 15:00
共同结束 = min(17:00, 24:00, 19:00) = 17:00
第一班次设置 = 15:00–17:00
```

该设置的栏位定位含义：

- A、B、C员工在 `15:00` 及以前到岗打卡，均进入第一班次的上班栏。
- A、B、C员工在 `17:00` 及以后离岗打卡，均进入第一班次的下班栏。
- 因此 `15:00–17:00` 是自动选择第一组上班/下班栏位的共同分界，不是把三组员工的真实工作时间统一改成两小时。
- A、B、C的真实考勤仍分别按 `08:00–17:00`、`15:00–00:00（次日）`、`13:00–19:00` 核算。

## 7. 客服内部判断模板

```text
先识别员工组和每组全部打卡时间
→ 先分钟化并处理跨夜 → 取最大上班时间 → 取最小下班时间
→ 开始早于结束：输出共同区间和时长
→ 开始不早于结束：判定无共同区间，保留独立班次
```
