# 针打蓝牙/WiFi 打印机客服知识库

## 0. GPT 使用说明

当客户提到 `针打蓝牙`、`蓝牙打印`、`WiFi打印`、`速印通APP`、`APP闪退`、`搜索不到设备`、`安装不上驱动`、`打印不清楚`、`模版`、`苹果手机打印`、`Mac打印`、`平板打印` 时，优先检索本文件。

默认处理顺序：

1. 先确认客户使用场景：手机/电脑/Mac/平板，安卓/鸿蒙/iPhone，蓝牙/WiFi/USB。
2. 再确认基础状态：APP版本、驱动版本、机器型号、自检页、机器是否放纸且纸张被吸入、网络是否为 `2.4G/非5G`。
3. 让客户发截图/视频，不要凭一句话直接判断。
4. 对 APP、驱动、固件类问题，先核实是否最新版本，再指导卸载重装、手动安装、刷机或转技术。
5. 客户要退货时，先说明可以协助调试和远程排查；若仍坚持且符合平台规则，再按平台售后处理。

## 1. quick_triage 快速排查卡

### 1.1 必问信息

- 手机系统：安卓、鸿蒙、iPhone，系统版本是否刚升级。
- 设备：手机、Mac、Windows电脑、苹果笔记本、iPad/平板。
- 连接方式：蓝牙、WiFi、USB、手机热点。
- APP版本：是否是当前最新版本；不要只问“有没有重装过”。
- 机器状态：是否开机、是否放纸、纸张是否被机器吸入、指示灯是闪烁还是常亮。
- 自检页：是否有 IP 地址、蓝牙名称、PID、固件版本、WiFi模式。
- 问题证据：客户截图、打印预览图、打印效果图、操作视频。

### 1.2 不能直接跳过的判断

- 搜索不到 WiFi/设备：先确认机器放纸、自检页 IP、是否 2.4G 网络、是否第一次搜索约 3 分钟。
- APP异常：先看 APP 版本和系统版本，再判断是否需要最新安装包。
- 打印效果差：先看预览是否正常，再区分手机 APP 参数、电脑驱动阈值、纸张规格、截图/底色问题。
- 模版问题：先确认客户用的是 APP 模版、Excel 表格、后台定制模版，还是第三方软件文档。
- 蓝牙/WiFi概念：蓝牙款不等于所有设备都能蓝牙连接；苹果手机/平板可按 WiFi 方式使用时，需提供 WiFi 教程。

## 2. app_and_install APP 安装与登录

### 2.1 最新版本优先

- 客户 APP 异常、闪退、打不开、打印转圈、模版重影、手机搜索不到设备时，优先检查 APP 是否为最新版本。
- 表内出现过多个版本记录，例如 `1.1.8`、`1.1.8-23`、`1.3.4(8)`；这些是历史客服记录，不等于永久最新。
- 给客户发送安装包前，先确认当前团队资料库/快捷语链接是否已更新，避免客户下载老版本后反复卸载。
- 表内记录的安卓/鸿蒙安装链接：`https://grozziie.zjweiting.com:8033/tht/app_file/china_test_version.apk`

安全话术：

> 亲，APP异常一般需要先确认版本。麻烦您打开 APP 看一下当前版本号，或者先卸载旧版本，我这边发您当前最新安装包，复制链接到浏览器里下载安装后再试一下。

### 2.2 安卓/鸿蒙安装问题

- 安卓或鸿蒙系统升级后，旧 APP 可能出现闪退、打不开、打印异常。
- 鸿蒙系统提示“纯净模式”时，可按：设置 -> 系统和更新 -> 纯净模式 -> 退出。
- 下载或安装时提示风险，可让客户确认来源为官方提供安装包后点击信任；不要用“病毒”字眼吓到客户。
- 安装包需要通过浏览器打开；必要时可建议客户使用 QQ 浏览器打开链接和保存文档。
- 第一次打开 APP 后进不去，可先切换手机流量再打开，之后通常可正常使用。

安全话术：

> 亲，这个提示一般是手机系统的安全模式拦截。您可以进入手机“设置-系统和更新-纯净模式”里退出纯净模式，再复制链接到浏览器下载安装。安装后第一次打开可以先切换到手机流量试一下。

### 2.3 iPhone / iPad / 平板

- 非中国版 iPhone 下载 APP，可在 App Store 搜索 `Grozziie`。
- 蓝牙款客户使用苹果手机时，可解释为苹果手机可按 WiFi 方式打印，并提供 WiFi 教程。
- 表内记录：普通机型和安卓/鸿蒙平板不支持；iPad/苹果平板是否支持要结合机型和 WiFi 使用方式判断，不要一口咬定。
- 蓝牙机器不支持笔记本通过蓝牙直接连接打印；电脑端应走 USB/WiFi 驱动等方式。

安全话术：

> 亲，苹果手机这边一般是按 WiFi 方式连接打印，不是直接像普通蓝牙耳机那样连接。麻烦您先确认机器已开机并放纸，我这边按 WiFi 设置步骤一步一步帮您看。

### 2.4 APP 登录和账号

- 现版本 APP 可优先引导游客登录，不要让客户卡在创建账号上。
- 同一个账号换设备或卸载重装后，客户自己编辑保存的模版可能不会保留；后台上传的模版可搜索到。
- 创建账号失败时，重点检查邮箱格式。
- APP 显示英文时，可退出重新登录/重新进入，一般会恢复中文。

安全话术：

> 亲，您可以先用游客登录，不一定要先创建账号。重新安装或换手机后，自己本地编辑保存的模版可能不会同步，后台上传的模版可以通过订单号或关键词再搜索。

## 3. wifi_driver WiFi 连接和驱动

### 3.1 WiFi 设置基本规则

- WiFi 设置时优先使用 `2.4G/非5G` 网络，不要使用 5G 网络。
- 设置过程机器必须开机，前面要放纸，且纸张被机器吸入。
- 第一次搜索 WiFi/打印机可能需要约 `3分钟`，不要让客户刚点搜索就退出。
- 搜索不到时，先打印自检页，看是否有 IP 地址、WiFi 模式、蓝牙名称和 PID。
- 手机热点可以用于无 WiFi 环境；iPhone 热点需要打开“最大兼容性”。

安全话术：

> 亲，WiFi设置时请先确认机器前面已放纸并吸入，手机连接的是 2.4G 网络，不要用 5G。第一次搜索可能需要 3 分钟左右，麻烦先耐心等搜索完成；如果还搜不到，请拍一下自检页给我看 IP 地址和版本信息。

### 3.2 搜索不到 WiFi/设备

排查顺序：

1. 机器是否在身边、已开机、已放纸并吸入。
2. 手机/电脑和机器是否在同一个 WiFi。
3. WiFi 是否为非 5G；用热点时是否打开最大兼容。
4. 第一次搜索是否等待约 3 分钟。
5. 自检页是否有 IP 地址；没有 IP 通常说明 WiFi 未设置成功。
6. 指示灯：常亮通常表示网络已连接；闪烁则可能需要重新设置 WiFi。
7. APP 和机器固件是否匹配、是否需要更新/刷机。

安全话术：

> 亲，先帮您判断一下是 WiFi 没设置成功，还是设置成功后搜索不到。麻烦您打印一张自检页，并拍一下机器右侧灯是闪烁还是常亮；如果没有 IP 地址，我们需要先重新设置 WiFi。

### 3.3 WiFi 驱动安装不上

- 不要直接选择 WiFi 选项；应先通过“自动/搜索”完成 WiFi 设置或搜索。
- 如果误选 USB 选项，可能导致 WiFi 驱动安装不上。
- 电脑是有线网络、没有 WiFi，但需要 WiFi 驱动时，可手动安装驱动并根据自检页 IP 创建 IP 端口。
- IP 地址正常时，可手动创建 IP 端口并选择该端口。
- 多台电脑使用时，第一次可通过 USB 设置 WiFi，设置成功后，同一 WiFi 下其他电脑可直接安装 WiFi 驱动并搜索。
- 缺少 `.NET` 时，先指导安装 .NET 后再装驱动；表内路径曾记录为 `C盘 Program Files(x86) > PrintSetUp... > run安装NET`，实际以安装包路径为准。

安全话术：

> 亲，WiFi驱动安装前需要先确认机器已经成功连上 WiFi。请先打印自检页看有没有 IP 地址；如果有 IP，我可以指导您手动创建 IP 端口。如果没有 IP，就需要先重新设置 WiFi。

### 3.4 IP 地址变化

- 机器关机或网络环境变化后，IP 地址可能变化，需要重新设置或重新创建端口。
- 客户长时间不使用，可建议断电或重新放纸后再试。

安全话术：

> 亲，机器关机或网络变化后 IP 地址可能会变化。如果原来的端口不能打印，麻烦重新打印自检页看一下当前 IP，我们再按新的 IP 设置端口。

## 4. bluetooth_and_device_limits 蓝牙与设备限制

- 蓝牙机器不支持笔记本直接通过蓝牙打印。
- 快递方手机 APP，例如表内提到的“掌中通/掌中宝”类，不支持直接手机蓝牙打印；电脑端打印通常不限制软件。
- 手机端通常只能通过官方 APP 打印，其他软件里的文件需要先下载/保存到手机本地，再用 APP 打印。
- APP 不支持云打印，没有 IMEI 号。
- 连接时手机需要在机器旁边。

安全话术：

> 亲，我们这款机器手机端需要通过官方 APP 打印，其他软件里的文件可以先保存到手机本地，再在 APP 里选择文档打印。电脑端可以按驱动方式打印，不能直接用笔记本蓝牙连接。

## 5. mac_and_computer Mac 与电脑打印

### 5.1 Mac 安装驱动

- Mac 安装驱动后，需要打开系统设置/系统偏好设置 -> 打印机与扫描仪，检查能否找到驱动。
- 如果列表里没有，需要手动添加打印机并选择对应驱动。
- 打印乱码时，先检查接口是否正确，可换 USB 接口；再取消打印队列、重启电脑和打印机，必要时卸载重装驱动。

安全话术：

> 亲，Mac 驱动安装完成后，还需要到“系统设置-打印机与扫描仪”里确认是否已添加这台打印机。如果没有显示，请手动添加一次对应驱动后再测试打印。

### 5.2 平台组件打印白纸/缩放异常

- Mac 能打印测试标签，但抖音平台打印白纸时，检查抖音打印组件设置，去掉“打印旋转90度”和“反转宽高”。
- 苹果电脑打印不全或缩放很多时，检查打印预览方向、首选项纸张规格、文档纸张规格是否一致。
- 电脑打印太糊时，可降低驱动阈值，调整后重启文档再打印。

## 6. mobile_printing 手机 APP 打印文件

- 手机只能通过官方 APP 打印。
- QQ 浏览器、管家婆、德邦系统、扫描软件、快递方 APP 等内容，需要先保存到手机本地，再进入 APP 选择文档/图片打印。
- ERP/进销存等系统：电脑上可按驱动打印，手机端通常不支持直接打印，只能通过官方 APP 打印本地文件。
- 客户问“能不能通过扫描打印”：可让客户把扫描图片保存到本地，再在 APP 中选择文件打印。
- 客户找不到文件时，让客户确认保存后的文件名，选择新命名的表格/文档。

安全话术：

> 亲，手机端需要通过我们的 APP 打印。您可以先在原软件里把文件下载或另存到手机本地，然后打开 APP，选择“文档/图片”找到这个文件再打印。

## 7. template 模版与定制

### 7.1 模版处理原则

- 客户要做模版时，先确认机型、订单号、纸张规格、是否空白纸、是否带框纸。
- 客户提供自带框体的模版时，提交前必须问清楚是打印在空白纸上，还是打印在这种带框纸上。
- 模版制作前应告知时效，表内建议约 `24小时`；着急客户可帮忙催促。
- 不要没提交模版就向客户索要好评。
- 订单号和物流单号不能混淆；做模版用错单号会导致后续很难查找。

安全话术：

> 亲，做模版前我先帮您确认一下：您是用空白纸打印，还是用已经带框的纸张打印？麻烦再发一下纸张尺寸、机型和订单截图，这样提交后不容易反复修改。

### 7.2 APP 模版和 Excel

- APP 模版里可以调整字体大小、部分选项和表格操作；客服要自己熟悉 APP。
- 如果客户要函数公式，先确认是 APP 模版还是 Excel 表格。APP 模版暂不适合复杂函数，建议用 Excel 表格编辑后保存到手机本地打印。
- 客户找不到后台模版时，可按订单号/关键词搜索；制作模版时也应以订单号标记，方便后续查找。
- 时间格式没有客户想要的样式时，可用文本模式编辑。

## 8. print_quality 打印效果排查

### 8.1 先看预览

- 打印不全、白纸、方向不对、缩放异常、字体加粗、线条缺失，都要先让客户发预览截图和打印效果图。
- 如果预览里已经不对，先调整文档、纸张规格、方向、保持纵横比、表格线宽、字体等。
- 如果预览正常但打印异常，再看驱动阈值、APP 对比度、纸张放置、打印质量、机器状态。

安全话术：

> 亲，麻烦先发一下 APP/电脑里的打印预览截图，再发一张实际打印出来的效果图。我先帮您判断是文件预览问题，还是打印参数需要调整。

### 8.2 常见效果问题

| 问题 | 优先判断 | 处理方法 |
|---|---|---|
| 打印不全 | 纸张规格、方向、保持纵横比、预览是否完整 | 选对应纸张规格，保持纵横比，检查纸张高度和文档大小 |
| 白纸 | 预览是否有空白页、文档是否有空白页面 | 检查预览页数和空白页面，删除空白页再打印 |
| 线条不全 | 模版线条太细、打印质量低 | 加粗线条，电脑端提高打印质量，手机端加大线宽 |
| 打印太糊/有重影 | 对比度/阈值过高，或打印的是截图 | 手机对比度调低，表内曾建议约 `210`；电脑驱动阈值调低，重启文档后再打印 |
| 字体太粗 | 预览是否已加粗 | 预览粗则先改文档；预览正常则降低阈值/对比度 |
| 文字不清楚 | 字体不适合针打 | 建议使用黑体；不要承诺字体完全一致 |
| 打印倾斜 | 放纸和压杆位置 | 右边扳手调到最高位置，五指平推放纸 |
| 有底色截图 | 截图/图片底色太重 | 建议去掉底色或降低对比度，避免损伤色带 |
| 横线没有 | 驱动、针头、线宽 | 查驱动名称，打印测试页排除针头问题，再调打印质量或线宽 |

### 8.3 图片、截图、PDF

- 截图和 PDF 本身可能没有原文档清晰。
- 带底色图片不建议直接打印，容易效果差，也可能增加色带损耗。
- 客户打印图片时，让客户保存图片到手机本地，再在 APP 里按文档/图片路径选择打印。

## 9. firmware_and_hardware 固件、刷机和硬件

- 自检页很重要：可看机器型号、版本、蓝牙名称、PID、IP 地址。
- 程序刷错或版本过旧时，需要用最新刷机程序刷机，并设置蓝牙名称和 PID。
- 表内出现过 `149`、`V152`、`V154` 等版本记录；生成回复时不要直接承诺某个版本为当前最新，需按技术资料确认。
- 苹果手机搜索不到蓝牙设备、手机搜索不到设备、版本不匹配等情况，可能需要更新 APP 和固件。
- 开机灯闪烁、放手就关机等异常，可尝试刷机；仍异常则转售后检测。
- 功率资料：待机约 `5W`，峰值约 `65W`，频率 `50-60Hz`，输入电压 `100V-220V`，输出 `24V 2.5A`。
- 机器长时间不用出现断电/重启需求时，先区分是正常节能保护还是异常断电；必要时检查插座、电源和机器状态。

安全话术：

> 亲，这个需要先看自检页上的版本和机器信息。麻烦您打印自检页发我，我确认是否是 APP/固件版本不匹配；如果需要更新程序，我会按技术步骤再指导您。

## 10. return_and_after_sales 退货与售后

- 无理由退货超过退货期时，可说明按平台规则无法直接退货，但可以继续协助调试或远程排查。
- 客户觉得不好用想退货时，先挽留并说明可以协助调试；如果客户仍坚持且在规则期内，按平台 7 天退换/售后流程处理。
- 客户申请退货后，取件方式通常在售后页面选择。
- 客户想换更贵的机器时，平台换货一般只能同款调换；退换期内可申请退货后重新下单。

安全话术：

> 亲，先别着急退，我这边可以继续帮您调试，很多连接和打印效果问题都可以通过 APP、网络或驱动设置解决。如果您调试后仍不想保留，并且订单符合平台售后规则，可以按售后页面继续申请处理。

## 11. do_not_say 禁用/高风险表达

- 不要让客户反复卸载重装，却不核实 APP 版本。
- 不要给客户发旧 APP 链接或旧驱动。
- 不要客户一问就转远程；先看截图、自检页和基础设置。
- 不要混淆蓝牙、WiFi、USB 连接方式。
- 不要说“5G WiFi也可以”，表内多次要求使用非 5G/2.4G。
- 不要说“蓝牙款所有设备都能蓝牙打印”；笔记本蓝牙、快递方手机 APP 蓝牙打印均有明确限制。
- 不要把针式打印机引导到热敏机预览页面或热敏纸逻辑。
- 不要没提交模版就让客户给好评。

- 不要在没看预览图/打印图前直接判断机器坏了。

## 12. safe_templates 常用客服话术

### 12.1 APP 异常/闪退

亲，APP异常需要先确认版本。麻烦您看一下当前 APP 版本号，或者先卸载旧版本，我发您当前最新安装包，复制链接到浏览器里下载安装后再试。安装后第一次打开如果进不去，可以先切换手机流量打开一次。

### 12.2 WiFi 搜索不到机器

亲，先确认机器已开机，前面已放纸并吸入，手机连接的是 2.4G 网络，不要用 5G。第一次搜索可能需要 3 分钟左右。若还是搜不到，麻烦打印自检页发我，我看一下有没有 IP 地址和机器版本。

### 12.3 手机热点设置 WiFi

亲，没有 WiFi 的情况下可以用手机热点设置。如果是苹果手机热点，请打开“最大兼容性”，再重新设置；设置时机器前面也要放纸并吸入。

### 12.4 电脑有线网络但要装 WiFi 驱动

亲，这种情况可以手动安装驱动并创建 IP 端口。请先打印自检页，看上面有没有 IP 地址；如果有，我按这个 IP 指导您创建端口并选择对应驱动。

### 12.5 手机第三方软件打印

亲，手机端需要通过我们的 APP 打印。您可以先在原软件里把文件下载或另存到手机本地，然后打开 APP，选择文档/图片找到这个文件再打印。

### 12.6 打印不清楚/太糊

亲，麻烦先发一下打印预览截图和实际打印效果图。我先判断是文件本身、纸张规格，还是打印参数问题。手机打印可以尝试降低对比度，电脑打印可以降低驱动阈值后重新打开文档再打印。

### 12.7 模版定制

亲，做模版前我先确认一下：您的纸张是空白纸，还是已经带框的纸？麻烦发一下纸张尺寸、机型和订单截图。模版制作通常需要一些时间，我会帮您提交并跟进。

### 12.8 退货前挽留

亲，这个问题我们可以先帮您调试，很多是 APP 版本、网络或纸张规格设置导致的。如果您方便，先发截图/视频给我，我一步一步帮您看；如果调试后仍不想保留，再按平台售后规则处理。
