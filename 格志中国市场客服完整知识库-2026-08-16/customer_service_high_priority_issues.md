# 客服高频高优先级问题矩阵

## 1. 结论摘要

最需要优先优化的不是单纯问得最多的问题，而是“问得多 + 处理慢会带来售后、退款、差评或成交损失”的问题。按当前知识库，优先级最高的 12 类如下：

1. 退款、退货、换货、补发、赔偿
2. 投诉、差评、平台介入、小二介入、客服态度
3. 发票、税务资料、开票撤销或重开
4. 维修、质保、收费、寄修地址、过保争议
5. 热敏机不打印、端口、驱动、任务卡住
6. 热敏机白纸、黑条、白线、打印不清、打印不全
7. 针式打印机不打印、脱机、任务卡住、端口错误
8. 针式打印机色带安装、打印淡、走纸/感应器异常
9. M880 考勤机日期、时间、班次、09 组跨天、15 组卡片识别
10. 蓝牙/WiFi 打印机搜不到设备、无 IP、Windows IP 端口
11. 售前适配、型号确认、系统/连接方式/纸张尺寸确认
12. 物流催发、改地址、拦截、运费、差价、优惠券

## 2. 高频率 + 高优先级总表

| 优先级 | 问题类别 | 频率依据 | 风险/价值 | 自动客服动作 | RAG 命中策略 |
|---:|---|---|---|---|---|
| P0 | 退款/退货/换货/补发/赔偿 | 历史话术约 77-82 条，且售后文件反复出现 | 金额、平台规则、差评风险最高 | 只安抚、收集订单状态/型号/问题证据，不作结果承诺 | 优先命中 `global_refund_return_high_risk` |
| P0 | 投诉/差评/平台介入/客服态度 | 历史话术约 43 条，投诉/差评信号约 8 条 | 容易触发平台介入、处罚或恶意骚扰风险 | 先道歉安抚，记录诉求和已沟通情况，升级人工 | 优先命中 `global_complaint_bad_review_high_risk` |
| P0 | 发票/开票/重开/撤销/税号 | 历史话术约 77-86 条 | 财务和税务资料高敏感 | 只判断需求方向，避免复述敏感资料，转人工财务 | 优先命中 `global_invoice_high_risk` |

| P2 | 运费、差价、优惠券、价保 | 历史约 41-67 条 | 涉及金额和活动规则 | 不承诺返还，按订单页、商品页和人工确认 | 高风险词提升，命中金额/规则类 chunk |
| P2 | 教程、驱动、视频、链接 | 历史资料/教程/链接约 152 条 | 提速价值很高，但错发会造成反复 | 必须说明适用型号、用途、第一步，不编造链接 | 高频缓存 + 视频素材卡片规则 |

## 3. 自动处理优先队列

### 3.1 第一优先：必须先稳住风险

触发词：

- 退款、退货、换货、仅退款、补发、赔偿、赔钱
- 差评、投诉、平台介入、小二、12315、工商、客服态度
- 发票、税号、抬头、重开、撤销、邮箱
- 维修费、过保、寄修地址、质保、检测结果
- 改地址、电话、物流单号、运费、差价、优惠券

处理原则：

- 先安抚，再收集必要信息。
- 不说“一定退款/一定换/肯定报销/马上开好/保证能改地址”。
- 不让客户去平台外沟通或提供平台外账号。
- 不复述完整地址、电话、税号、订单号等敏感信息。
- 需要人工核实的，RAG 只输出“收集信息 + 风险提示 + 人工确认”。

### 3.2 第二优先：能靠步骤快速解决的技术问题

优先自动回复：

- 端口怎么改、点打印没反应、任务卡住
- 热敏机打印白纸、打印不全、黑条、白线
- 针打色带怎么装、打印淡、吸纸异常
- M880 日期怎么调、时间不准、班次怎么设、09 组跨天
- WiFi/蓝牙搜不到、没有 IP、Windows IP 端口

处理原则：

- 先确认型号、系统、连接方式、纸张或班次。
- 有视频素材的问题，回复中优先搭配千牛素材卡片。
- 视频不能单独发送，必须配一句“先做哪一步、做完反馈什么”。
- 两轮仍未解决，或客户已经发图片/视频证明质量问题，升级处理。

### 3.3 第三优先：影响成交的售前问题

高频场景：

- 客户问“买哪个款式支持？”
- 客户问“我的系统/平台/纸张能不能用？”
- 客户问“有没有链接/耗材/色带/考勤卡？”
- 客户问“蓝牙、WiFi、USB 哪个支持？”

处理原则：

- 不急着推荐，先问使用场景。
- 打印机先确认：打印内容、纸张宽度、联数、系统、连接方式。
- 考勤机先确认：人数、班次、是否停电打卡、是否需要响铃。
- 给商品链接时说明用途，不只发链接。

## 4. RAG 快速命中配置建议

### 4.1 高频缓存必须保留

这些问题应该始终放在 `high_frequency_queries.json` 里，命中后直接进对应卡片，不再检索长知识库：

| 客户问法 | 推荐 card_id |
|---|---|
| 日期怎么调 / 考勤机日期不对 | `attendance_date_video` |
| 色带怎么装 / 打印淡 | `attendance_ribbon_video` 或 `dot_matrix_ribbon_install` |
| 端口怎么改 / 点打印没反应 | `thermal_no_response_usb_port` 或 `dot_matrix_no_print_offline_queue` |
| 可以退货吗 / 我要退款 | `global_refund_return_high_risk` |
| 我要投诉 / 已经差评 | `global_complaint_bad_review_high_risk` |
| 开发票 / 发票重开 | `global_invoice_high_risk` |
| 搜不到设备 / WiFi 连不上 | `wifi_search_device_not_found` |
| IP 端口怎么设置 | `wifi_windows_ip_port` |

### 4.2 检索排序建议

1. 高风险词命中：退款、投诉、差评、发票、赔偿、维修费、地址、差价。
2. 高频 query 精确命中。
3. 产品线识别：考勤机、热敏机、针打、蓝牙/WiFi。
4. 意图识别：售前、教程、故障、售后、物流、发票。
5. 卡片优先，source chunk 兜底。
6. 如果卡片答案和 chunk 冲突，以天猫规则和高风险卡片优先。

## 6. 训练后的客服回复方向

好回复的共同点：

- 短、亲切、先回应客户问题。
- 不只说“稍等/看视频/点链接”，而是给下一步。
- 先确认型号、系统、连接方式、纸张或班次。
- 有图片/视频时先利用客户已给信息，不重复问。
- 高风险问题不作最终承诺，先记录并核实。

不合适回复的共同点：

- 客户问具体问题，只回“看视频”或只发链接。
- 没确认型号，把热敏机、针打、考勤机话术混用。
- 涉及退款、发票、维修费、补发、运费时直接承诺。
- 客户情绪激动时争辩、反问、让客户先改评价。
- 多轮没解决还继续机械重复同一段话。
